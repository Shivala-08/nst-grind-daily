## Problem Statement

You are given the root of a binary search tree (BST) and the lowest and highest boundaries of a valid range as low and high. Your task is to trim the tree such that all its remaining node values fall strictly within the inclusive range [low, high].

Trimming the tree should not change the relative structure of the elements that remain in the tree (i.e., any remaining node&#39;s descendant relationship must be preserved). Your solution must return the root of the newly modified trimmed binary search tree.

User Task Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function trim_bst(), which takes the root node and two integers low and high as input parameters.

### Input
The first line of input contains three space-separated integers: N (the number of nodes), low (the lower bound), and high (the upper bound).

The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.

Note: The binary tree is constructed using the given level order traversal. Once a node is marked as -1, no further information about its children is provided.

### Output
Return the root node of the trimmed tree. The system will output the sorted inorder traversal values of the resulting tree.

### Example
5 2 4
3 1 4 -1 2
Output
2 3 4
Explanation

The original node values are [1, 2, 3, 4] in sorted order. The target inclusive range is [2, 4]. Node 1 is strictly less than the low boundary (2), so it is dropped, and its right child (2) is pulled up to link directly to the left pointer of the root node (3). The elements remaining within the valid range are 2, 3, and 4.

## Solution

```py
'''
class Node:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
'''

def trimBST(root, low, high):
    if not root:
        return None

    # Newton School uses root.data instead of root.val
    if root.data < low:
        return trimBST(root.right, low, high)

    if root.data > high:
        return trimBST(root.left, low, high)

    root.left = trimBST(root.left, low, high)
    root.right = trimBST(root.right, low, high)

    return root
```
