## Problem Statement

You are working with a large dataset of scores of 5 matches of a player in a competitive online game. You need to identify matches where the player scored above a certain threshold. After filtering the scores, you also need to calculate the average score of these matches having score more than a certain threshold. The dataset is provided as an array of player scores of each match.

Question:

Implement a JavaScript function named analyzeScores that:

 * Extracts matches where the player has a score greater than or equal to 50.

 * Calculates the average score of these Matches.

 * Returns 0 if no match has a score greater than or equal to 50.

The function must return average score of the Matches.

### Input
scores: an array containing scores of all the matches

### Output
average of scores of all matches having score above than a certain threshold

### Example
Example:
Input: [ 45, 75, 55, 80]
Output: 70

## Solution

```js
function analyzeScores(scores) {
    // Extract matches where the player has a score greater than or equal to 50
    const filteredScores = scores.filter(score => score >= 50);
    
    // Return 0 if no match has a score greater than or equal to 50
    if (filteredScores.length === 0) {
        return 0;
    }
    
    // Calculate the average score of these Matches
    const totalScore = filteredScores.reduce((sum, score) => sum + score, 0);
    const averageScore = totalScore / filteredScores.length;
    
    return averageScore;
}
```
