## Problem Statement

Given an integer array nums, return the number of longest increasing subsequences.

Note: The sequence has to be strictly increasing.

### Input
User Task
Since this is a functional problem, you don't have to input anything. You just need to complete the findNumberOfLIS() function that takes an integer array nums as the parameter and returns the number of longest increasing subsequences.

Custom Input
The first line of the input contains a single integer n, representing the size of the array nums.
The second line of the input contains n space separated integers representing elements of the array nums.

### Output
Return the number of longest increasing subsequences.

### Example
Sample Input
5
1 3 5 4 7
Output
2
Explanation
The two longest increasing subsequences are [1, 3, 4, 7] and [1, 3, 5, 7].

## Solution

```py
def findNumberOfLIS(nums):
    n = len(nums)
    if n == 0:
        return 0

    length = [1] * n
    count = [1] * n
    max_len = 1

    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                if length[j] + 1 > length[i]:
                    length[i] = length[j] + 1
                    count[i] = count[j]
                elif length[j] + 1 == length[i]:
                    count[i] += count[j]
        max_len = max(max_len, length[i])

    return sum(count[i] for i in range(n) if length[i] == max_len)
```
