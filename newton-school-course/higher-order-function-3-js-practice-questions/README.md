## Problem Statement

Create a function called parent that returns another function. The returned function should take two arguments, x and y, and return the product of x and y.

### Input
first line of input should contain only 2 space-separated numbers

### Output
product of given numbers

### Example
Input
2 5

Output
10

Explanation
function parent when invoked, it returns a new function, which when invoked with 2 and 5 as its argument, returns 10 because 2*5=10

## Solution

```js
function parent() {
  return function(x, y) {
    return x * y;
  };
}
```
