## Problem Statement

You are tasked with implementing a Priority Queue data structure supporting various operations like:

 * push(x): Insert a new element x into the Min Heap.

 * getMin(): Return the minimum element from the Min Heap without removing it.

 * pop(): Remove and return the minimum element from the Priority Queue.

## Solution

```py
import heapq

class PriorityQueue:
    def __init__(self):
        self.heap = []
        
    def push(self, x):
        heapq.heappush(self.heap, x)
        
    def getMin(self):
        if self.heap:
            return self.heap[0]
        return -1
        
    def pop(self):
        if self.heap:
            return heapq.heappop(self.heap)
        return -1
```
