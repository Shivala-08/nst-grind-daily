## Problem Statement

You are given two objects, obj1 and obj2. Your task is to write a function mergeAndLogObjects(obj1, obj2) that takes in two objects, merges them, and logs the result.

 * If both objects have the same property, the value from obj2 should overwrite the value from obj1.

 * If a property exists in only one object, it should be included in the merged object as is.

Requirements:

 * Write a function mergeAndLogObjects(obj1, obj2) that merges the two objects.

 * After merging, log the final merged object to the console.

### Input
This is a functional problem hence you don't have to take any input.

Both obj1 and obj2 are simple objects with string, number, or boolean values (no nested objects).

The function should merge the objects, with obj2's properties taking priority over obj1's properties in case of conflicts.

### Output
The function should log the merged object

### Example
Sample Input:
{ "name": "Bob", "country": "USA" }
{ "city": "Chicago", "country": "Canada" }

Sample output:
{name: "Bob",country: "Canada",city: "Chicago"}

function mergeAndLogObjects(obj1, obj2) {
  // Merge both objects using the spread operator
  const mergedObj = { ...obj1, ...obj2 };
