## Problem Statement

A collection named vehicles stores details of cars owned by a rental company. Each document looks like this:

 

{

 _id: ObjectId,

 model: String,

 company: String,

 isAvailable: Boolean

}

 

Due to a bulk return, all cars from the company "Toyota" have now become available for rent again. You need to update all such entries to set isAvailable as true.

Write the MongoDB query to perform this update and then write the find query to retreive the data.

## Solution

```js
db.vehicles.updateMany(
  { company: "Toyota" },
  { $set: { isAvailable: true } }
);

db.vehicles.find({ company: "Toyota" });
```
