## Problem Statement

Write a function sortObjectKeys(obj) that accepts a JavaScript object and returns a new object with its keys sorted in lexicographical (alphabetical) order.

The corresponding values should remain associated with their original keys.

If the input object is empty, return an empty object. 

Note: The key of the objects must be written in the string format as explained below with an example.

{"b": "2", "a": "1", "c": "3"}

 

### Input
A single line string representing an object in JSON format.
{"b": "2", "a": "1", "c": "3"}

### Output
A JSON string representing the new object with sorted keys.

{"a":"1","b":"2","c":"3"}

### Example
Input: {"b": "2", "a": "1", "c": "3"}
Output: {"a":"1","b":"2","c":"3"}

## Solution

```js
function sortObjectKeys(obj) {
  if (!obj || typeof obj !== "object" || Array.isArray(obj)) {
    return {};
  }

  const sortedObj = {};
  const sortedKeys = Object.keys(obj).sort();

  for (const key of sortedKeys) {
    sortedObj[key] = obj[key];
  }

  return sortedObj;
}
```
