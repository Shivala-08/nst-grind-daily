## Problem Statement

Your team is building a small command-line utility for an internal application. The utility is used by the onboarding team to generate a personalized welcome message for newly added users.

Your task is to create a Node.js script that processes command-line arguments. The script will receive the user&#39;s name and city as arguments when executed from the terminal.

You need to implement a function, greetUser, that takes these command-line arguments and generates a personalized welcome message.

The utility should work correctly for different names and cities provided through the command line.

const process = require("process");

function greetUser() {
  // Extract name and city from command-line arguments
  const name = process.argv[2];
