## Problem Statement

You are managing a MongoDB collection named students that stores university student records. Each document in the students collection includes:

 * name (string)

 * age (number)

 * department (string)

 * gpa (number)

Due to a system update, you want to increase the age of all students in the collection by 1 year. Print all the values after the update.

## Solution

```js
db.students.updateMany({}, { $inc: { age: 1 } });
db.students.find();
```
