## Problem Statement

The books collection in a local library database contains details about various books such as title, author, and genre. The library has decided to add a new field named available to every book document, which indicates whether the book is currently available for borrowing.

Task:

Write a MongoDB query to update all documents in the books collection by adding a new field available and setting its value to true.

 

📄 Sample Document Schema (Before Update):
 

{

 title: "The Alchemist",

 author: "Paulo Coelho",

 genre: "Fiction"

}

 

 

✅ Sample Document Schema (After Update):
 

{

 title: "The Alchemist",

 author: "Paulo Coelho",

 genre: "Fiction",

 available: true

}

## Solution

```js
db.books.updateMany(
  {},
  { $set: { available: true } }
)
```
