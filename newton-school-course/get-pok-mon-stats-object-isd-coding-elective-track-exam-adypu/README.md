## Problem Statement

To help trainers quickly assess a Pok&eacute;mon&#39;s performance metrics, implement an asynchronous function getPokemonStatsObject that accepts a Pok&eacute;mon name, fetches its data from the PokeAPI https://pokeapi.co/api/v2/pokemon/name, and returns an object mapping each stat name to its corresponding base_stat value.

### Output

## Solution

```js
async function getPokemonStatsObject(name) {
    const response = await fetch(`https://pokeapi.co/api/v2/pokemon/${name.toLowerCase()}`);
    const data = await response.json();
    
    return data.stats.reduce((statsObj, currentStat) => {
        statsObj[currentStat.stat.name] = currentStat.base_stat;
        return statsObj;
    }, {});
}
```
