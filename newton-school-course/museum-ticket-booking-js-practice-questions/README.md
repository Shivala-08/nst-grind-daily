## Problem Statement

You are tasked with implementing a function (calculateTicketPrice) for Museum Ticket Booking in JavaScript. The function should calculate the ticket price based on the following conditions:

 * Base Price: The base ticket price is $12.

 * Age Discount: If the visitor is under 12 years old, apply a discount of $5 to the base price.

 * Weekend Markup: If the visit is on a weekend, add a surcharge of $3 to the ticket price.

 * Student Discount: If the visitor has a student card, subtract $2 from the ticket price.

calculateTicketPrice accepts the following parameters:

 * age (number): The age of the visitor.

 * isWeekend (boolean): Whether the visit is on a weekend (true or false).

 * hasStudentCard (boolean): Whether the visitor has a student card (true or false).

The function should return the price of the ticket.

### Input
age (number): The age of the visitor.
isWeekend (boolean): Whether the visit is on a weekend (true or false).
hasStudentCard (boolean): Whether the visitor has a student card (true or false).

### Output
The ticket price (Integer)

### Example
Input:
23
true
false

Output: 
15

Explanation:
base price: 12
As visitor's age is more than 12, No discount will be applied.
It's weekend, hence, $3 must be added, price goes to 15.
He's not a student, hence, no Student discount will be applied.
Hence, Total Price: 15

## Solution

```js
function calculateTicketPrice(age, isWeekend, hasStudentCard) {
  let price = 12; // Base price

  if (age < 12) {
    price -= 5; // Age Discount
  }

  if (isWeekend) {
    price += 3; // Weekend Markup
  }

  if (hasStudentCard) {
    price -= 2; // Student Discount
  }

  return price;
}
```
