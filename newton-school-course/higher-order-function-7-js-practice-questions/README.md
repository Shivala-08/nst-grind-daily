## Problem Statement

Define a function parent that accepts two parameters: a callback function and a number (num). The parent function should return a new function.

When this new function is executed, it will invoke the callback, passing num as the argument, and return the result of that callback.

### Input
first line of input contains a custom callback function in oneline
second line of input contains the argument for the second parameter of function parent i.e., num. This argument num will always be a digit.

### Output
The first line of output contains a function that, when called, returns the result of invoking the callback function with num as its argument.

Note:- this function is being invoked internally to check the output.

### Example
Input
(num) =&gt; num + 5
3
Output
8

Explanation
When parent is invoked, it returns a new function. When this new function is executed with 3 as its argument, it invokes the callback function, passing 3 as the argument to callback. The callback adds 5 to the number, resulting in 10, which is returned.

## Solution

```js
const parent = (callback, num) => () => callback(num);
```
