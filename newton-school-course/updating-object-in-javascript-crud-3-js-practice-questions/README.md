## Problem Statement

You are given a JSON object, a key, and a new value. Your task is to update the value of the specified key in the given object and return the object.

Constraints:

The key will always be present in the JSON object. The JSON object will have at most 100 keys. The new value will not contain spaces.

### Input
A JSON object
A key (string)
A new value (string or number without spaces)
Input format (single line):

&lt;jsonObject&gt; &lt;key&gt; &lt;newValue&gt;

### Output
the updated JSON object.

### Example
Input:
{"product":"Phone","price":"800","brand":"Apple"} price 900
Output:
{"product":"Phone","price":"900","brand":"Apple"}

## Solution

```js
const removeKeyFromObject = (obj, keyToRemove) => {
  // Create a shallow copy of the object to avoid mutating the original one
  const newObj = { ...obj };
  
  // Delete the specified key if it exists
  delete newObj[keyToRemove];
  
  return newObj;
};
```
