## Problem Statement

You are given an array prices where prices[i] is the price of a given stock on the ith day.

Find the maximum profit you can achieve. You may complete as many transactions as you like (i.e., buy one and sell one share of the stock multiple times) with the following restrictions:

 * After you sell your stock, you cannot buy stock on the next day (i.e., cooldown one day).

Note: You may not engage in multiple transactions simultaneously (i.e., you must sell the stock before you buy again).

### Input
User Task
Since this is a functional problem, you don't have to input anything. You just need to complete the maxProfit() function that takes an integer array prices as its parameter and returns an integer representing the maximum profit you can achieve.

Custom Input:
The first line of the input contains a single integer n, representing the size of the array prices.
The second line of the input contains n space-separated integers representing elements of the array prices.

### Output
Return an integer representing the maximum profit you can achieve.

### Example
Sample Input
5
1 2 3 0 2

Sample output
3

Explanation
Transactions = [buy, sell, cooldown, buy, sell].
Profit = (2 - 1) + (2 - 0) = 3

## Solution

```py
import sys
from typing import List


def maxProfit(prices: List[int]) -> int:
    if not prices:
        return 0

    hold = -prices[0]
    sold = float("-inf")
    rest = 0

    for price in prices[1:]:
        prev_hold = hold
        prev_sold = sold
        prev_rest = rest

        hold = max(prev_hold, prev_rest - price)
        sold = prev_hold + price
        rest = max(prev_rest, prev_sold)

    return int(max(sold, rest))


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        print(0)
        return

    # If the first token is n and the remaining tokens equal n, treat token 0 as count;
    # otherwise treat all tokens as prices.
    nums = [int(x.strip("[](),")) for x in data]
    if len(nums) > 1 and nums[0] == len(nums) - 1:
        prices = nums[1:]
    else:
        prices = nums

    print(maxProfit(prices))


if __name__ == "__main__":
    solve()
```
