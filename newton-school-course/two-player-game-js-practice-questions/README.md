## Problem Statement

You are given an array where the scores of two players, Naman and Arun, are recorded alternately for each turn. Naman will start the game and the scores appear sequentially. The first player to receive a negative score loses the game. Write a program to determine the winner based on this rule and stop processing as soon as a player loses. There is always a winner.

### Input
This is a functional problem hence you don't have to take any input.

You will receive an array as an input of size n.

25

### Output
A string which represents an name of a player that wins.

### Example
Sample Input :
1 4 7 3 0 -2 -4 5

Sample Output :
Naman

Explanation : The score of Naman are [ 1, 7, 0, -4 ] whereas the score of Arun are [ 4, 3, -2, 5] since Arun scores negative number first he looses.

## Solution

```js
function findWinner(scores) {
    // Naman starts first (index 0, 2, 4, ...) and Arun goes second (index 1, 3, 5, ...)
    for (let i = 0; i < scores.length; i++) {
        // Check if the current player's score is negative
        if (scores[i] < 0) {
            // Even indices belong to Naman, so if Naman gets a negative score, Arun wins.
            // Odd indices belong to Arun, so if Arun gets a negative score, Naman wins.
            return i % 2 === 0 ? "Arun" : "Naman";
        }
    }
}
```
