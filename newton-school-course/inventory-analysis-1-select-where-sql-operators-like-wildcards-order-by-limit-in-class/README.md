## Problem Statement

You are given a products table with following columns - 

 product_id, product_name, category, brand, price, rating, reviews_count, and in_stock. Write SQL queries to perform the following operations:

 Retrieve (product_name,rating,reviews_count) for the top product based on rating. If ratings are the same, prioritize the product with the higher number of reviews.

 Implement Page 1 pagination with a page size of 3 include only product_name,price.

 Implement Page 2 pagination with the same page size of 3 include only product_name,price.

 Implement Page 3 pagination with the same page size of 3 include only product_name,price.

 Retrieve product_name,price for the 3 cheapest products that are currently in stock.

## Solution

```js
SELECT product_name, rating, reviews_count 
FROM products 
ORDER BY rating DESC, reviews_count DESC 
LIMIT 1;


SELECT product_name, price 
FROM products 
LIMIT 3 OFFSET 0;

SELECT product_name, price 
FROM products 
LIMIT 3 OFFSET 3;

SELECT product_name, price 
FROM products 
LIMIT 3 OFFSET 6;

SELECT product_name, price 
FROM products 
WHERE in_stock = true 
ORDER BY price ASC 
LIMIT 3;
```
