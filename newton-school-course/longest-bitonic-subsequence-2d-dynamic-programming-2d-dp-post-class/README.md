## Problem Statement

Given an array of positive integers. Find the maximum length of Bitonic subsequence. 

A subsequence of array is called Bitonic if it is first strictly increasing, then strictly decreasing. Return the maximum length of bitonic subsequence.

 

Note : A strictly increasing or a strictly decreasing sequence should not be considered as a bitonic sequence

### Input
User Task
Since this is a functional problem, you don't have to input anything. You just need to complete the lbs() function that takes an array nums as a parameter return the length of longest Bitonic array.

Custom Input
The first line of the input contains a single integer n, representing the size of the array "nums".
The second line of the input contains n space separated integers representing elements of the array "nums".

### Output
Return the length of longest Bitonic array.

### Example
Sample Input
8
1 11 2 10 4 5 2 1
Sample Output
6
Explanation
A Longest Bitonic Subsequence of length 6 is 1, 2, 10, 4, 2, 1

## Solution

```py
def lbs(nums):
    n = len(nums)
    if n < 3:
        return 0

    # inc[i]: length of longest strictly increasing subsequence ending at index i
    inc = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i] and inc[j] + 1 > inc[i]:
                inc[i] = inc[j] + 1

    # dec[i]: length of longest strictly decreasing subsequence starting at index i
    dec = [1] * n
    for i in range(n - 1, -1, -1):
        for j in range(n - 1, i, -1):
            if nums[j] < nums[i] and dec[j] + 1 > dec[i]:
                dec[i] = dec[j] + 1

    # A valid bitonic sequence must strictly increase AND strictly decrease,
    # so both inc[i] > 1 and dec[i] > 1 must hold at peak index i.
    ans = 0
    for i in range(n):
        if inc[i] > 1 and dec[i] > 1:
            ans = max(ans, inc[i] + dec[i] - 1)

    return ans
```
