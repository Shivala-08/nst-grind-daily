## Problem Statement

PixelForge Studios wants to analyze wallet balances across account tiers to identify high-value player segments.

Table schema:

CREATE TABLE players (
 player_id INT PRIMARY KEY,
 player_name VARCHAR(50),
 region VARCHAR(30),
 account_tier VARCHAR(20),
 player_status VARCHAR(20),

Tasks:

1. Calculate the total wallet balance per account tier.

2. Calculate the average wallet balance per account tier.

3. Show only account tiers whose total wallet balance exceeds ₹150,000.

4. Sort the result by total balance in descending order.

### Output

--------------+----------------------+--------------------

(1 row)

## Solution

```js
SELECT 
    account_tier, 
    SUM(wallet_balance) AS total_wallet_balance, 
    AVG(wallet_balance) AS avg_wallet_balance
FROM 
    players
GROUP BY 
    account_tier
HAVING 
    SUM(wallet_balance) > 150000
ORDER BY 
    total_wallet_balance DESC;
```
