## Problem Statement

Given a 2D grid heights of size rows &times; columns, where heights[i][j] represents the height at cell (i, j), your task is to find the minimum effort required to travel from the top-left cell (0, 0) to the bottom-right cell (rows - 1, columns - 1)(i.e., 0-indexed). You can move up, down, left, or right, and you wish to find a route that requires the minimum effort.

The effort of a path is defined as the maximum absolute difference in heights between any two consecutive cells along that path.

Return the minimum effort required to travel from the top-left cell to the bottom-right cell.

### Input
User Task
As this is a functional problem, you don't need to take input. Your task is to complete the function: minimumEffortPath() which takes a 2D list heights representing the heights of each cell in the grid, and returns the minimum effort required to travel from the top-left to the bottom-right cell.

Custom Input
 * The first line contains two space-separated integers rows and columns — the dimensions of the grid.
 * The next rows lines each contain columns space-separated integers — the values of the 2D array heights.
 

### Output
Return the minimum effort required to travel from the top-left cell to the bottom-right cell.

### Example
Input:
2 2
5 10 
8 1 

Output:
7

Explanation: 

There are two possible paths from cell (0, 0) to (1, 1):

Path 1: (0,0) → (0,1) → (1,1) 
Heights: 5 → 10 → 1 
Effort = max(|5 − 10|, |10 − 1|) = max(5, 9) = 9

Path 2: (0,0) → (1,0) → (1,1) 
Heights: 5 → 8 → 1 
Effort = max(|5 − 8|, |8 − 1|) = max(3, 7) = 7

Among these, Path 2 requires the least effort. So, the minimum effort required to reach the destination is 7.

```py
import heapq
from typing import List


def minimumEffortPath(heights: List[List[int]]) -> int:
    rows, cols = len(heights), len(heights[0])
    dist = [[float("inf")] * cols for _ in range(rows)]
    dist[0][0] = 0

    # Min-heap storing (max_effort_so_far, row, col)
    pq = [(0, 0, 0)]
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while pq:
        effort, r, c = heapq.heappop(pq)

        if r == rows - 1 and c == cols - 1:
            return effort

        if effort > dist[r][c]:
            continue

        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols:
                step_effort = abs(heights[nr][nc] - heights[r][c])
                next_effort = max(effort, step_effort)

                if next_effort < dist[nr][nc]:
                    dist[nr][nc] = next_effort
                    heapq.heappush(pq, (next_effort, nr, nc))

    return 0
```
