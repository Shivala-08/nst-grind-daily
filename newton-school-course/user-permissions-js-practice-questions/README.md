## Problem Statement

The function assignAccess should take four arguments which are :

 * featureAccess:callback function

 * fallbackAccess:callback function

 * checkPermissions:callback function

 * userId:string or number

The assignAccess function should:

 * Call checkPermissions with userId as its arguments, to determine if the user has access to the premium feature. This function will return either a truthy value if the user has permissions or falsey value in case user does not have permission.

 * If the user has permission, it should call the featureAccess function with the userId as the argument, and return the result.

 * If the user does not have permission, it should call the fallbackAccess function instead, with userId as the argument, and return the result.

### Input
first line of input is a callback function written in oneline representing featureAccess
second line of input is a callback function written in oneline representing fallbackAccess
third line of input is a callback function written in oneline representing checkPermissions
fourth line of input represents userId, written in oneline

### Output
first line of output represent the result of featureAccess or fallbackAccess whichever is invoked

### Example
Input
(userId) =&gt; "User " + userId + " has access to the premium feature"
(userId) =&gt; "User " + userId + " has access to the basic feature"
(userId) =&gt; userId?false:true
42

Output

Explanation
since checkPermissions returns a falsey value, fallbackAccess was invoked with 42 as its argument

## Solution

```js
function assignAccess(featureAccess, fallbackAccess, checkPermissions, userId) {
  // Check user permissions
  const hasPermission = checkPermissions(userId);

  // If user has permission, call featureAccess and return its result
  if (hasPermission) {
    return featureAccess(userId);
  } else {
    // Otherwise, call fallbackAccess and return its result
    return fallbackAccess(userId);
  }
}
```
