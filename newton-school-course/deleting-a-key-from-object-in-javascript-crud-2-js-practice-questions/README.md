## Problem Statement

You are provided with a JavaScript object and a string representing the name of a key present/absent from the object. Your task is to return the object making sure it contains all the key value pair inside the object except the string provided.

### Input
space-separated object and string

### Output
object without the key whose name matches to the string

### Example
Input
{"id":"Kshitiz","title":"Manager","experience":"10","experienx":"10"} experienx

Output
{
 "id": "Kshitiz",
 "title": "Manager",
 "experience": "10"
}

## Solution

```js
const removeKeyFromObject = (obj, keyToRemove) => {
  // Create a shallow copy of the object to avoid mutating the original one
  const newObj = { ...obj };
  
  // Delete the specified key if it exists
  delete newObj[keyToRemove];
  
  return newObj;
};
```
