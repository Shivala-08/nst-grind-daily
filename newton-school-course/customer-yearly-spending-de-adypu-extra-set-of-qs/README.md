## Problem Statement

A retail shop maintains purchase records of its customers. Some invoices were incomplete, so a few purchase amounts are missing. For reporting purposes, any missing amount should be treated as zero. The shopkeeper wants to prepare a report for the year 2025, listing only those customers whose total spending is more than ₹4,000.

## Solution

```js
SELECT 
    c.cust_id,
    c.cust_name,
    COALESCE(SUM(o.amount), 0) AS total_spent
FROM Customers c
JOIN Orders o 
    ON c.cust_id = o.cust_id
WHERE YEAR(o.order_date) = 2025
GROUP BY c.cust_id, c.cust_name
HAVING COALESCE(SUM(o.amount), 0) > 4000;
```
