## Problem Statement

You are given an undirected, unweighted graph with $N$ vertices and $M$ edges, and two specified starting vertices $A$ and $B$.

Find all vertices $V$ ($1 \le V \le N$) such that:
\begin{enumerate}
 \item $V$ is reachable from both $A$ and $B$.
 \item The shortest path distance from $A$ to $V$ is equal to the shortest path distance from $B$ to $V$ (i.e., $d(A, V) = d(B, V)$).
\end{enumerate}

### Input
\begin{itemize}
 \item The first line contains two integers $N$ and $M$ ($1 \le N \le 10^5$, $0 \le M \le 10^5$) --- the number of vertices and edges.
 \item The second line contains two integers $A$ and $B$ ($1 \le A, B \le N$) --- the starting vertices.
 \item Each of the next $M$ lines contains two integers $u_i$ and $v_i$ ($1 \le u_i, v_i \le N$) --- representing an undirected edge between $u_i$ and $v_i$.
\end{itemize}
\textit{Note: The graph contains no self-loops and no multiple edges.}

### Output
Print a single line containing the space-separated IDs of all valid vertices $V$ in ascending order. 

If no such vertex exists, print $-1$.

### Example
Input:
5 4
1 2
1 3
2 3
3 4
4 5

Output:
3 4 5

Explanation:
Vertices $A$ and $B$ themselves are valid candidates if $d(A, A) = d(B, A)$ or $d(A, B) = d(B, B)$, respectively. Vertices that are unreachable from either $A$ or $B$ must be excluded.

## Solution

```py
from collections import deque
import sys


def solve():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return

    n = int(data[0])
    m = int(data[1])
    a = int(data[2])
    b = int(data[3])

    adj = [[] for _ in range(n + 1)]
    idx = 4
    for _ in range(m):
        u = int(data[idx])
        v = int(data[idx + 1])
        adj[u].append(v)
        adj[v].append(u)
        idx += 2

    # Function to compute shortest paths using BFS
    def bfs(start):
        dist = [-1] * (n + 1)
        queue = deque([start])
        dist[start] = 0

        while queue:
            u = queue.popleft()
            for v in adj[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    queue.append(v)
        return dist

    distA = bfs(a)
    distB = bfs(b)

    result = []
    for i in range(1, n + 1):
        # A node is valid if it's reachable from both and distances are equal
        if distA[i] != -1 and distB[i] != -1 and distA[i] == distB[i]:
            result.append(i)

    if not result:
        print("-1")
    else:
        print(*(result))


if __name__ == "__main__":
    solve()
```
