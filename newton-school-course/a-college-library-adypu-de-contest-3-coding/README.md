Question

Write a query to display the CSE students who have been issued 2 or more books.

Output must display exactly these columns:

 * student_name

 * total_books_issued

Sort the output by total_books_issued in descending order.

### Output

(5 rows)

## Solution

```js
SELECT s.student_name,
       COUNT(*) AS total_books_issued
FROM students s
JOIN issues i ON s.student_id = i.student_id
WHERE s.department = 'CSE'
GROUP BY s.student_name
HAVING COUNT(*) >= 2
ORDER BY total_books_issued DESC;
```
