## Problem Statement

You are a security guard at a club entrance.

Your job is simple:

 * If someone is an "admin" &rarr; call the onAllowed function

 * If someone is anything else &rarr; call the onDenied function

But here&#39;s the rule &mdash; you must use a closure to remember the role.

Step 1 &mdash; Create a function createAccess(role) that remembers the role.

Step 2 &mdash; It should return another function that takes two callbacks:

 * onAllowed &rarr; called if role is "admin"

 * onDenied &rarr; called if role is anything else

Note: No need to call the createAccess function. The function will be called by the background code. You also do need to print anything.

### Input
First line: the role of the user (string).

### Output
Print "Access granted!" if the role is "admin".

Print "Access denied!" otherwise.

### Example
INPUT 1:
admin

OUTPUT 1:
Access granted!

-------------

INPUT 2:
user

OUTPUT 2:
Access denied!

## Solution

```js
function createAccess(role) {
    return function(onAllowed, onDenied) {
        if (role === "admin") {
            onAllowed();
        } else {
            onDenied();
        }
    };
}
```
