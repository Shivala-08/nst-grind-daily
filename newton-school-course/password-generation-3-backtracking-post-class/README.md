## Problem Statement

You are given an integer n. Your task is to generate and print all valid passwords of length n using characters from the following set:

chars = "aeiou1234@"

A character may be used any number of times in a password.

A password is considered valid if it satisfies all of the following conditions:

 * No two consecutive characters in the password are the same.

 * The password contains at most two numeric characters (1, 2, 3, or 4).

 * @ cannot appear in the first or last position of the password.

 * @ cannot appear more than once in the password.

 * No two numeric characters are adjacent to each other.

 * The password must contain at least one vowel (a, e, i, o, u).

Print all possible valid passwords of length n.

For n = 5:

Valid passwords: a1e2o, e@a1u, aeiou, i2a4e, o1@ie, u3e2a

Invalid passwords: @aeio (@ at first position), aeio@ (@ at last position), a12eo (adjacent digits 1,2), a@e@i (@ used twice), 12341 (no vowels present)

### Input
A single integer n, representing the length of each password.

### Output
Print every possible password of length n. (you can print in any order)

Print each password on a new line.

import sys


def solve():

  if not input_data:

  n = int(input_data[0])

  chars = 'aeiou1234@'
  vowels = set('aeiou')
  digits = set('1234')

  # Precompute valid types for quick checks
  # 0: vowel, 1: digit, 2: '@'

  def get_type(c):
    if c in vowels:
      return 0
    if c in digits:
      return 1
    return 2

  results = []

  def backtrack(idx, path):
    if idx == n:
      # Check conditions
      # 1. No two consecutive characters are the same (handled during generation)
      # 2. At most two numeric characters
      num_digits = sum(1 for c in path if c in digits)
      if num_digits > 2:
        return
      # 3. '@' cannot appear in the first or last position
      if n > 0 and (path[0] == '@' or path[-1] == '@'):
        return
      # 4. '@' cannot appear more than once
      if path.count('@') > 1:
        return
      # 5. No two numeric characters are adjacent (handled during generation)
      # 6. Must contain at least one vowel
      if not any(c in vowels for c in path):
        return

      results.append(''.join(path))
      return

    for c in chars:
      # Condition 3 optimization for first position
      if idx == 0 and c == '@':
        continue
      # Condition 1: No two consecutive characters are the same
      if idx > 0 and path[-1] == c:
        continue
      # Condition 5: No two numeric characters are adjacent
      if idx > 0 and c in digits and path[-1] in digits:
        continue
      # Condition 4: '@' cannot appear more than once
      if c == '@' and '@' in path:
        continue

      path.append(c)
      backtrack(idx + 1, path)
      path.pop()

  backtrack(0, [])

  for res in results:
    print(res)
