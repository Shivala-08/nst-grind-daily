## Problem Statement

You are given a products table ,write an SQL query to display all the columns and categorise products into &#39;Low&#39;, &#39;Medium&#39;, and &#39;High&#39; based on their "price".

 * For price &lt; 50 "Low"

 * For price between 50 and 150 (included) "Medium"

 * For price greater than 150 "High"

Display the columns product_id, product_name, price & price_category

&lt;schema&gt;[{"name":"products","columns":[{"name":"product_id","type":"integer","primary_key":true},{"name":"product_name","type":"varchar(50)"},{"name":"price","type":"decimal(10,2)"}]}]&lt;/schema&gt;

 

### Output
Output Table shall contain below columns in the given order:
product_id
product_name
price
price_category

### Example

Sample Input:
Table: products

 
 
 product_id
 product_name
 price
 
 
 
 2Milk40
 4Soap99
 5Pizza199
 

Sample Output:

 
 
 product_id
 product_name
 price
 price_category
 
 
 
 2Milk40Low
 4Soap99Medium
 5Pizza199High

## Solution

```js
SELECT 
    product_id, 
    product_name, 
    price,
    CASE 
        WHEN price < 50 THEN 'Low'
        WHEN price BETWEEN 50 AND 150 THEN 'Medium'
        ELSE 'High'
    END AS price_category
FROM products;
```
