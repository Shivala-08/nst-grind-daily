Task:
Write a SQL query to rank bank accounts within each branch based on their balance, with the account having the highest balance receiving rank 1. Display the following columns:

 account_holder

 branch

 balance

 rn &mdash; the rank of the account within its branch

Order the final results by branch and then by rank in ascending order.

Hint: Use a window function to assign a sequential rank to accounts within each branch.

### Output

 Priya Mehta | Bangalore | 128000.00 | 1

(6 rows)

## Solution

```js
SELECT 
account_holder,branch,balance,
RANK() OVER (PARTITION BY branch
ORDER BY balance DESC) AS rn
FROM accounts;
```
