## Problem Statement

You are given an \`employees\` table:

+--------+---------------+-------------+--------+
| emp_id | emp_name | department | salary |
+--------+---------------+-------------+--------+
| 1 | Aarav Sharma | Sales | 60000 |
| 2 | Priya Nair | Tech | 48000 |
| 3 | Rahul Verma | Tech | 72000 |
+--------+---------------+-------------+--------+

Return the \`emp_name\` and \`salary\` of every employee in the \`Tech\` department.

### Output
 emp_name | salary 
-------------+--------
 Priya Nair | 48000
 Rahul Verma | 72000
(2 rows)

## Solution

```js
SELECT emp_name,salary FROM employees WHERE department = 'Tech'
```
