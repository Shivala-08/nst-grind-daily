## Problem Statement

Write a function processArray(array, callback) that applies the callback function to each element of the array and logs the result on the console.

Instructions:

 The function should have 2 parameters: array and callback.

 The callback function should be applied to each element and output must be printed on the console.

### Input
An array of numbers.
A callback function to process the elements.

### Output
The results of applying the callback function to each element, printed one at a time.

### Example
Example 1:
Input: 1 2 3
Output: 
 2
 4 
 6

## Solution

```js
function processArray(array, callback) {
    array.forEach(element => {
        console.log(callback(element));
    });
}
```
