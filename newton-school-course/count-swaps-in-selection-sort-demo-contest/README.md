## Problem Statement

You are given an array of integers. Perform Selection Sort on the array and count the number of swaps made during the sorting process. Print the total number of swaps performed.

Note: Using sort() or sorted() will definitely sort the array, but unfortunately they refuse to reveal the swap count. You&rsquo;ll have to do the work yourself.

### Input
* The first line contains an integer n — the number of elements in the array.
* The second line contains n space-separated integers.

### Output
Print a single integer — the total number of swaps performed by Selection Sort.

### Example
Example 1
Input:
5
4 3 2 1 5

Output:
2

Explanation:
Selection Sort swaps the smallest element with the first unsorted position.
For [4, 3, 2, 1, 5], swaps are: (4↔1) and (3↔2) → 2 swaps total.

Example 2
Input:
4
1 2 3 4

Output:
0

Explanation:
The array is already sorted, so no swaps are needed.

## Solution

```py
def count_selection_sort_swaps():
    import sys
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    arr = [int(x) for x in input_data[1:n+1]]
    
    swap_count = 0
    
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        
        # Only increment swap count and perform the swap if the minimum element 
        # is not already at its correct position
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
            swap_count += 1
            
    print(swap_count)

if __name__ == '__main__':
    count_selection_sort_swaps()
```
