## Problem Statement

You are given a number value.

Your task is to perform a series of operations on the number using Promises and .then() chaining.

The operations should be executed in the following order:

 Double the number

 Add 10 to the result

 Multiply the result by 3

Each operation must be written in a separate function that returns a Promise.

Functions to Create:

 double(value): Returns a Promise that resolves with the doubled value.

 addTen(value): Returns a Promise that resolves with the value increased by 10.

 multiplyByThree(value): Returns a Promise that resolves with the value multiplied by 3.

Requirements:

 Chain the functions using .then()

 Return the result from each .then() so it can be passed to the next function

 In the final .then(), print the result using console.log()

### Input
Input: You will be given a single number, value.

### Output
After performing all operations, log the final result.

### Example
Input:
5

Output:
60

## Solution

```js
function double(value) {
  return Promise.resolve(value * 2);
}

function addTen(value) {
  return Promise.resolve(value + 10);
}

function multiplyByThree(value) {
  return Promise.resolve(value * 3);
}

// Chaining the functions as required:
double(value)
  .then(result => {
    return addTen(result);
  })
  .then(result => {
    return multiplyByThree(result);
  })
  .then(finalResult => {
    console.log(finalResult);
  });
```
