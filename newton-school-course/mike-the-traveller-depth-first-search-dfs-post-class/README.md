## Problem Statement

Mike is a traveller and loves visiting new countries. He recently visited a country with $n$ cities connected by bi-directional roads.

The road network can be represented as an undirected graph with $n$ vertices, where each vertex represents a city and each edge represents a road connecting two cities.

Mike is currently in city $A$ and wants to travel to city $B$ using the roads. Determine whether it is possible to reach city $B$ from city $A$ by travelling through zero or more roads.

Print \`\`YES\`\` if such a path exists; otherwise, print \`\`NO\`\` (without quotes).

### Input
The first line contains four integers $n$, $m$, $A$, and $B$ ($1 \le n \le 10^5$, $0 \le m \le 10^5$, $1 \le A, B \le n$) --- the number of cities, the number of roads, Mike's starting city, and his destination.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), denoting that there is an undirected road between cities $u$ and $v$.

It is guaranteed that there is at most one road between any pair of cities.

### Output
Print a single string:

\begin{itemize}
\item \`\`YES\`\` if it is possible to reach city $B$ from city $A$.
\item \`\`NO\`\` otherwise.
\end{itemize}

You can output the answer in any case (upper or lower). For example, the strings \`\`yEs\`\`, \`\`yes\`\`, \`\`Yes\`\`, and \`\`YES\`\` will be recognized as positive responses.

### Example
Input:
5 4 1 5
1 2
2 3
3 4
4 5

Output:
YES

Explanation:
A path may contain any number of roads. In the first example, Mike can travel along the path
$1 \rightarrow 2 \rightarrow 3 \rightarrow 4 \rightarrow 5$.

In the second example, cities $1$ and $5$ belong to different connected components, so it is impossible to travel from city $1$ to city $5$.

```py
from collections import defaultdict, deque
import sys


def solve():
    # Read all inputs from standard input
    input = sys.stdin.read
    data = input().split()

    if not data:
        return

    n = int(data[0])
    m = int(data[1])
    A = int(data[2])
    B = int(data[3])

    # If the start and destination are the same
    if A == B:
        print("YES")
        return

    # Build the adjacency list for the graph
    graph = defaultdict(list)
    idx = 4
    for _ in range(m):
        u = int(data[idx])
        v = int(data[idx + 1])
        graph[u].append(v)
        graph[v].append(u)
        idx += 2

    # BFS to find if B is reachable from A
    visited = [False] * (n + 1)
    queue = deque([A])
    visited[A] = True

    found = False
    while queue:
        curr = queue.popleft()

        if curr == B:
            found = True
            break

        for neighbor in graph[curr]:
            if not visited[neighbor]:
                visited[neighbor] = True
                queue.append(neighbor)

    if found:
        print("YES")
    else:
        print("NO")


if __name__ == "__main__":
    solve()
```
