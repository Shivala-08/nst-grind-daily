## Problem Statement

You are given the root of a binary search tree (BST) and a key to delete. Your task is to delete the node containing the key while strictly maintaining all properties of a valid BST.

Mandatory Invariant Rule:

When deleting a node that possesses two children, you must explicitly replace its value with its inorder predecessor (the maximum value found within its left subtree) and then recursively delete that predecessor node from the left subtree.

If the key does not exist in the tree, leave the tree unaltered.

User Task

Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function delete_node(), which takes the root node and the key to be deleted, returning the root of the modified tree.

 

### Input
The first line of input contains two space-separated integers, N and key, representing the total number of nodes and the value to delete.
The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.

### Output
Return the root node of the modified binary search tree after deletion.

### Example
Input
6 15
15 10 20 8 12 -1 -1
Output
12 10 20 8
Explanation
The target key is 15 (the root), which has two children. Its inorder predecessor is 12 (maximum in left subtree). We replace 15 with 12 and delete the old node 12. The final modified structure in level order is [12, 10, 20, 8].

## Solution

```py
'''
class Node:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
'''
def delete_node(root, key):
    if not root:
        return None

    # Search for the node to delete
    if key < root.val:
        root.left = delete_node(root.left, key)
    elif key > root.val:
        root.right = delete_node(root.right, key)
    else:
        # Node with only one child or no child
        if not root.left:
            return root.right
        elif not root.right:
            return root.left

        # Node with two children: replace with inorder predecessor (max in left subtree)
        curr = root.left
        while curr.right:
            curr = curr.right
        
        # Replace value with inorder predecessor's value
        root.val = curr.val
        
        # Recursively delete the inorder predecessor from left subtree
        root.left = delete_node(root.left, curr.val)

    return root
```
