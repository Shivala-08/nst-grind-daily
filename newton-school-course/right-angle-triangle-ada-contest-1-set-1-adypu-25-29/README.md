## Problem Statement

You are given a positive integer N. Your task is to print a right-angled triangle pattern of asterisks (*) such that:

 * The triangle has exactly N rows.

 * Each asterisk is separated by a single space.

Note: View the example output below to clearly understand the required pattern.

### Input
The first and only line of input contains a positive integer N.

### Output
Print a right-angled triangle pattern of asterisks (*).

### Example
Input
5
Output
\text{*} 
\text{* *} 
\text{* * *} 
\text{* * * *} 
\text{* * * * *}

Input
3
Output
\text{*} 
\text{* *} 
\text{* * *}

## Solution

```js
# Read input N
n = int(input())

# Loop through each row from 1 to N
for i in range(1, n + 1):
    # Print i asterisks separated by a space
    print(" ".join(["*"] * i))
```
