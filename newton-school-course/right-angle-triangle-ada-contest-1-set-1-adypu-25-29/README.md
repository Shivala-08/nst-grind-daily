## Problem Statement

You are given a positive integer N. Your task is to print a right-angled triangle pattern of asterisks (*) such that:

 * The triangle has exactly N rows.

 * Each asterisk is separated by a single space.

Note: View the example output below to clearly understand the required pattern.

### Input
The first and only line of input contains a positive integer N.

### Output
Print a right-angled triangle pattern of asterisks (*).

### Example
Input
5
Output
\text{*} 
\text{* *} 
\text{* * *} 
\text{* * * *} 
\text{* * * * *}

Input
3
Output
\text{*} 
\text{* *} 
\text{* * *}

## Solution

```js
def print_triangle(n, current=1):
    if current > n:
        return
    
    # Helper function to generate a row of 'current' asterisks separated by spaces without using '*'
    def make_row(count):
        if count == 1:
            return "*"
        return "* " + make_row(count - 1)
    
    print(make_row(current))
    print_triangle(n, current + 1)

# Read input N
n = int(input())
print_triangle(n)
```
