## Problem Statement

You are given the root of a binary search tree (BST) and an integer X. Your task is to find both the floor and the ceiling of X within the tree.

Definitions:

Floor: The greatest value in the BST that is less than or equal to X.

Ceiling: The smallest value in the BST that is greater than or equal to X.

If either the floor or ceiling value does not exist in the tree, represent that value as -1.

User Task

Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function find_floor_ceil(), which takes the root node and the integer X as input parameters and returns a list containing two integers: [floor, ceiling].

### Input
The first line of input contains two space-separated integers, N and X, representing the number of nodes in the tree and the target key value.
The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.

### Output
Return a list of two elements where the first element is the floor value and the second element is the ceiling value.

### Example
Input
5 25
20 8 22 4 12 -1 -1
Output
22 -1
Explanation
The keys present in the tree are 4, 8, 12, 20, 22. For X = 25, the largest value less than or equal to 25 is 22 (Floor). There is no value greater than or equal to 25, so the ceiling is -1.

```py
'''
class Node:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
'''

def find_floor_ceil(root, x):
    floor = -1
    ceil = -1
    
    curr = root
    while curr:
        if curr.val == x:
            floor = curr.val
            ceil = curr.val
            return [floor, ceil]
        
        if curr.val < x:
            floor = curr.val  # Potential floor candidate
            curr = curr.right
        else:
            ceil = curr.val   # Potential ceiling candidate
            curr = curr.left
            
    return [floor, ceil]
```
