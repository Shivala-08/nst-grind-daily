## Problem Statement

The GridStrike Operations Dashboard uses a player segmentation grid to monitor player populations across regions and account tiers.

Table schema:

CREATE TABLE players (
 player_id INT PRIMARY KEY,
 player_name VARCHAR(50),
 region VARCHAR(30),
 account_tier VARCHAR(20),
 player_status VARCHAR(20),
 wallet_balance DECIMAL(10,2)
);

Tasks:

1. Display region and account tier combinations.

2. Show the number of Active players in each combination.

3. Apply a HAVING filter to display only combinations containing more than 1 Active player.

### Output
 region | account_tier | player_count 
--------+--------------+--------------
 North | Gold | 2
(1 row)

## Solution

```js
SELECT 
    region, 
    account_tier, 
    COUNT(*) AS player_count
FROM players
WHERE player_status = 'Active'
GROUP BY region, account_tier
HAVING COUNT(*) > 1;
```
