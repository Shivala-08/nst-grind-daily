## Problem Statement

You are given a \`customers\` table and an \`orders\` table:

customers orders
+-------------+--------+ +----------+-------------+--------+
| customer_id | name | | order_id | customer_id | amount |
+-------------+--------+ +----------+-------------+--------+
| 1 | Aarav | | 101 | 1 | 500 |
| 2 | Priya | | 102 | 1 | 300 |
| 3 | Rahul | | 103 | 3 | 700 |
+-------------+--------+ +----------+-------------+--------+

Return every customer&#39;s \`name\` alongside the \`amount\` of each of their orders,

including customers who have no orders (their \`amount\` should be NULL). Order the

result by \`customer_id\`, then by \`order_id\`.

### Output
name | amount
-------+--------
Aarav | 500
Aarav | 300
Priya |
Rahul | 700
(4 rows)

## Solution

```js
SELECT c.name, o.amount
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
ORDER BY c.customer_id, o.order_id;
```
