## Problem Statement

PixelForge Studios wants a quick overview of player distribution and wallet performance across the GridStrike player base.

Current players table:

Tasks:

1. Write a query that shows how many players belong to each region.

2. Write a query that shows, per account tier:

 - Total wallet balance

 - Average wallet balance

### Output

(3 rows)

--------------+----------------------+------------------------

## Solution

```js
SELECT region, COUNT(*) AS player_count
FROM players
GROUP BY region;
```
