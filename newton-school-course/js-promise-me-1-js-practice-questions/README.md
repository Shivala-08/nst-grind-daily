## Problem Statement

Complete the function promiseMe which returns a Promise that resolves or rejects after a given time.

Your function should:

 
 Accept two parameters:

 
 
 time (a number): the delay in milliseconds

 

 
 data (any type): the value to be returned or thrown

 

 
 

 If data is not undefined, the Promise should resolve with data after the specified delay.

 if data is undefined then reject the promise with the "Error"

 

 The delay should be created using setTimeout.

### Input
write both inputs in 1 line with space:

A number time – the delay in milliseconds.
A value data – the value to resolve or reject with.

### Output
Resolves to the data given as input

A Promise that:

 Resolves to data after time milliseconds if data is not undefined.

### Example
Input:
1000 hi

Output:
true true

## Solution

```js
function promiseMe(time, data) {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            if (data !== undefined) {
                resolve(data);
            } else {
                reject("Error");
            }
        }, time);
    });
}
```
