## Problem Statement

You are given an integer array nums of size n and an integer array operations of size m.

Process the values in operations from left to right. For each value x:

 * Find the current maximum element in nums.

 * Remove one occurrence of this maximum element.

 * Add x to it.

 * Insert the new value back into nums.

After all m operations are completed, find the maximum element in nums.

### Input
The first line contains two integers n and m — the number of elements in nums and the number of operations.

The second line contains n integers nums_1, nums_2, ..., nums_n — the initial elements of the array.

The third line contains m integers operations_1, operations_2, ..., operations_m — the values to be added one operation at a time.

### Output
Print a single integer — the maximum element in nums after all m operations have been performed.

### Example
Example 1:
Input4 3
3 7 2 5
-4 6 -2Output9Explanation
Initially, nums = [3,7,2,5].

For x=-4, the current maximum is 7. It becomes 3.
The array can now be viewed as [3,3,2,5].

For x=6, the current maximum is 5. It becomes 11.
The array can now be viewed as [3,3,2,11].

For x=-2, the current maximum is 11. It becomes 9.
The final maximum is 9.

## Solution

```py
import sys
import heapq

def solve():
    # Read all input from standard input
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    m = int(input_data[1])
    
    # Parse nums and operations
    nums = [int(x) for x in input_data[2:2+n]]
    operations = [int(x) for x in input_data[2+n:2+n+m]]
    
    # Create a max-heap by negating the values
    max_heap = [-num for num in nums]
    heapq.heapify(max_heap)
    
    # Process each operation
    for x in operations:
        # Pop the largest element (which is the smallest in our negative min-heap)
        current_max = -heapq.heappop(max_heap)
        
        # Add x to it
        new_val = current_max + x
        
        # Push the new value back into the heap
        heapq.heappush(max_heap, -new_val)
        
    # The answer is the maximum element remaining in the heap
    print(-max_heap[0])

if __name__ == '__main__':
    solve()
```
