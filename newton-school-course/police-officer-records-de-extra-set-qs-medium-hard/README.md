## Problem Statement

The police department maintains records of its officers and the stations they are assigned to. The data is stored in two tables: Police_Officers, Police_Stations .

The department wants a report of all officers earning more than 55,000, including their station information. For this report:

If an officer&rsquo;s email is missing, display &#39;No Email&#39;.

If an officer is not assigned to any station, display &#39;Unassigned&#39; as the station name.

The report should include the following columns: Officer ID, Officer Name, Email, Station Name, Designation, and Salary.

Additionally, the report should be sorted by salary in descending order, and for officers with the same salary, sorted by station name alphabetically.

## Solution

```js
SELECT 
    po.officer_id AS officer_id,
    po.officer_name AS officer_name,
    COALESCE(po.email, 'No Email') AS employee_email,
    COALESCE(ps.station_name, 'Unassigned') AS station_name,
    po.designation AS designation,
    po.salary AS salary
FROM Police_Officers po
LEFT JOIN Police_Stations ps ON po.station_id = ps.station_id
WHERE po.salary > 55000
ORDER BY po.salary DESC, station_name ASC;
```
