## Problem Statement

You are given two arrays of integers, arr1 and arr2.

Your task is to modify arr1 by performing the following operations:

 * 
 Take the union of arr1 and arr2, meaning you should combine the elements of both arrays while ensuring that the resulting arr1 contains only unique elements (no duplicates).

 

 * 
 Sort the updated arr1 in ascending order.

 

Note

 * 
 You do not need to print or log the result using console.log.

 

 * 
 Arrays are mutable, so the changes you make to arr1 will automatically be accessible and printed by the backend.

 

 

### Input
The first line of input contains the first array of numbers
The second line of input contains the second array of numbers

### Output
The first line of output contains an array having the union of both the arrays

### Example
Input

[1, 2, 3, 4]
[3, 4, 5, 6]

Output

[1, 2, 3, 4, 5, 6]

## Solution

```js
function findUnion(arr1, arr2) {
  // Combine both arrays using a Set to automatically remove duplicate elements
  const combinedSet = new Set([...arr1, ...arr2]);
  
  // Clear arr1 and push all unique sorted elements back into it
  arr1.length = 0;
  arr1.push(...Array.from(combinedSet).sort((a, b) => a - b));
}
```
