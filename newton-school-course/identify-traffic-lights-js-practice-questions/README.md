## Problem Statement

Write a program that takes the color of a traffic signal as input and displays the corresponding action.

A traffic signal can be Red, Yellow, or Green. Based on the input, output the corresponding message:

 * "Red" &rarr; "Stop"

 * "Yellow" &rarr; "Ready"

 * "Green" &rarr; "Go"

 * Any other color &rarr; "Invalid Color"

 

Note: This is a functional problem. Just return the corresponding action for the given color by completing the function.

### Input
The first line contains the traffic signal color (e.g., "Red", "Green", "Yellow" or anything else).

Note: This is a functional problem. You do not need to take input. 

### Output
A string representing the corresponding action based on the traffic signal color.

Note: You do not need to print anything; simply return the string from the function.

### Example

## Solution

```js
function getInstructionsFromSignal(color) {
    switch (color) {
        case "Red":
            return "Stop";
        case "Yellow":
            return "Ready";
        case "Green":
            return "Go";
        default:
            return "Invalid Color";
    }
}
```
