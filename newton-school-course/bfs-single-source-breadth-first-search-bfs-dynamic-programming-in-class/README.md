## Problem Statement

You are given a connected undirected graph with n vertices and m edges. Perform a Breadth-First Search (BFS) of the graph starting from the given source vertex src.

### Input
User Task:
Since this will be a functional problem, you don't have to take input. You just have to complete the function bfsOfGraph() that takes three parameter n representing number of nodes, a 2D array of edges of length m and source node as src.

Custom Input:
First line contains two integers n and m representing number of nodes and number of edges.
Next m lines will contain two space separated integers u and v representing undirected edge between them.
Next line will contain src representing source node.

### Output
Returns a list containing the BFS traversal of the graph starting from the source vertex according to the graph.

### Example
Input :
5 4
0 2
0 3
0 1
2 4
2

Output:
2 0 4 3 1

Explanation:
2 is connected to 0 and 4.
0 is connected to 2, 3, 1.
4 is connected to 2.
3 is connected to 0.
1 is connected to 0.

Thus, the BFS order is: 2 0 4 3 1

## Solution

```py
from collections import deque

def bfsOfGraph(n, edges, src):
    # Step 1: Build the adjacency list
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    
    # Optional: Sort neighbors to ensure a deterministic visit order 
    # (if the problem expects ascending order for tied nodes)
    for i in range(n):
        adj[i].sort()

    visited = [False] * n
    bfs_result = []
    
    # Step 2: Initialize queue and start BFS from src
    queue = deque([src])
    visited[src] = True
    
    while queue:
        node = queue.popleft()
        bfs_result.append(node)
        
        # Traverse all adjacent nodes
        for neighbor in adj[node]:
            if not visited[neighbor]:
                visited[neighbor] = True
                queue.append(neighbor)
                
    return bfs_result
```
