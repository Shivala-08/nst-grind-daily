## Problem Statement

You are given an undirected graph with $V$ vertices, numbered from $0$ to $V-1$, and $E$ edges.

A connected component in an undirected graph is a maximal subset of vertices such that there exists a path between any pair of vertices in this subset.

Your task is to count the total number of connected components in the graph.

### Input
The first line contains two space-separated integers $V$ and $E$ ($1 \le V \le 10^4$, $0 \le E \le 10^5$)~--- the number of vertices and edges in the graph, respectively.

Each of the next $E$ lines contains two space-separated integers $u$ and $v$ ($0 \le u, v &lt; V$, $u \neq v$)~--- representing an undirected edge between vertex $u$ and vertex $v$.

It is guaranteed that the graph contains no self-loops and no multiple edges.

### Output
Output a single integer~--- the number of connected components in the graph.

### Example
Input:
5 3
0 1
2 1
3 4

Output:
2

Input:
7 5
0 1
6 0
2 4
2 3
3 4

Output:
3

\begin{itemize}
 \item Edges are: $(0, 1)$, $(2, 1)$, and $(3, 4)$.
 \item Vertices $\{0, 1, 2\}$ form one connected component.
 \item Vertices $\{3, 4\}$ form another connected component.
\end{itemize}
Thus, there are $2$ connected components in total.

#include <bits/stdc++.h>
using namespace std;

void dfs(int node, const vector<vector<int>>& adj, vector<bool>& visited) {
    visited[node] = true;
    for (int neighbor : adj[node]) {
        if (!visited[neighbor]) {
            dfs(neighbor, adj, visited);
        }
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int V, E;
    if (!(cin >> V >> E)) return 0;

    vector<vector<int>> adj(V);
    for (int i = 0; i < E; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    vector<bool> visited(V, false);
    int connectedComponents = 0;

    for (int i = 0; i < V; ++i) {
        if (!visited[i]) {
            dfs(i, adj, visited);
            connectedComponents++;
        }
    }

    cout << connectedComponents << "\n";

    return 0;
}
