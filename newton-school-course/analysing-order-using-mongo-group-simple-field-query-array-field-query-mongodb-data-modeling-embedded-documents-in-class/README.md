 { "_id": 5, "customer_id": 102, "book_title": "Clean Code", "price": 900 },

 { "_id": 6, "customer_id": 101, "book_title": "Design Patterns", "price": 700 }

]

Write a MongoDB Aggregation Pipeline using $group to calculate the total amount spent by each customer.

Note: Output will be as total spent first and then customer_id. Sort by total_spent descending

 

### Output
[
 { total_spent: 1850, customer_id: 101 },
 { total_spent: 1650, customer_id: 102 },
 { total_spent: 800, customer_id: 103 }
]

## Solution

```js
db.orders.aggregate([
  {
    $group: {
      _id: "$customer_id",
      total_spent: { $sum: "$price" }
    }
  },
  {
    $sort: { total_spent: -1 }
  },
  {
    $project: {
      _id: 0,
      total_spent: 1,
      customer_id: "$_id"
    }
  }
]);
```
