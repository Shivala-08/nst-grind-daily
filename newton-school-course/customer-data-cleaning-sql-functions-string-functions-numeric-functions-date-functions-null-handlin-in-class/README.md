## Problem Statement

A customer database has inconsistencies: names are stored in mixed case, cities have random capitalisation, and email addresses were entered with surrounding spaces. Clean this data for a standardised CRM export.

Table schema:

CREATE TABLE customers (
 customer_id INT,
 full_name VARCHAR(100), -- e.g. &#39;rAHUL sHARMA&#39;
 city VARCHAR(50), -- e.g. &#39;mUMBAI&#39;
 email VARCHAR(150) -- e.g. &#39; Rahul@Test.COM &#39; (note the surrounding spaces)
);

customers table:

+-------------+--------------+-----------+---------------------+
| customer_id | full_name | city | email |
+-------------+--------------+-----------+---------------------+
| 101 | rAHUL sHARMA | mUMBAI | Rahul@Test.COM |
| 102 | pRIYA vERMA | dELHI | PRIYA@GMAIL.COM |
| 103 | aARAV mEHTA | bENGALURU | AARAV@OUTLOOK.COM |
| 104 | sNEHA gUPTA | cHENNAI | Sneha@Yahoo.COM |
| 105 | vIKRAM sINGH | kOLKATA | vikram@zestshop.com |
| 106 | nEHA kAPOOR | pUNE | neha@test.com |
+-------------+--------------+-----------+---------------------+

Write a query to display:

 The customer&#39;s full name in uppercase, labelled name_upper.

 The customer&#39;s city in lowercase, labelled city_clean.

 
 The customer&#39;s email after:

 
 removing any unnecessary spaces at the beginning or end, and

 converting it to lowercase,

 

 Label this column email_clean.

 

 A column named email_length that shows the number of characters in the cleaned email.

 Display the results ordered by email_length in ascending order.

### Output

(6 rows)

## Solution

```js
SELECT 
    customer_id,
    UPPER(full_name) AS name_upper,
    LOWER(city) AS city_clean,
    LOWER(TRIM(email)) AS email_clean,
    LENGTH(LOWER(TRIM(email))) AS email_length
FROM customers
ORDER BY email_length ASC;
```
