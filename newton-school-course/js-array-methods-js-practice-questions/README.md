## Problem Statement

You are given an array of numbers. Use appropriate array methods to find all numbers that are greater than 5. Complete the function getNumbersGreaterThan5 that accepts an array of integers nums and returns an array of numbers that are greater than 5.

### Input
The input takes the values of the input array separated by spaces.

### Output
Displays each element from the input array \`nums\` on a new line if it is greater than 5.

### Example
Sample Input: 1 2 3 9 10 7 5 4 3

Sample Output: 
9
10
7

Explanation: Only 9, 10, 7 are greater than 5 among the array values.

## Solution

```js
function getNumbersGreaterThan5(nums) {
    nums.filter(i) =>i>5
}
```
