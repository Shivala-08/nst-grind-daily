## Problem Statement

You are given a function named sumEvenIntegers that is intended to return the sum of all even integers in the array.

However, it currently contains a bug and does not return the correct result.

Your task is to identify and fix the issue so that the function works as expected.

### Input
A single line containing a number of space-separated integers.

### Output
A single integer: the sum of even numbers.

### Example
Input: 10 21 30 41 50 
Output: 90

Explanation:
Even indices are: 0, 2, and 4.
Hence, sum will be 10+30+50 = 90.

## Solution

```js
function sumEvenIntegers(arr) {
    let sum = 0;
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] % 2 === 0) {
            sum += arr[i];
        }
    }
    return sum;
}
```
