## Problem Statement

You are provided with an integer with variable name : "index", and you need to display the corresponding weekday name. The numbering of weekdays is as follows:

 * Monday

 * Tuesday

 * Wednesday

 * Thursday

 * Friday

 * Saturday

 * Sunday

Print Invalid for any other input value.

### Input
Would take number

### Output
Print appropriate weekday name.

### Example
Sample Input:
3

Sample Output:
Wednesday

## Solution

```js
// index variable is already given
if (index === 1) {
  console.log("Monday");
} else if (index === 2) {
  console.log("Tuesday");
} else if (index === 3) {
  console.log("Wednesday");
} else if (index === 4) {
  console.log("Thursday");
} else if (index === 5) {
  console.log("Friday");
} else if (index === 6) {
  console.log("Saturday");
} else if (index === 7) {
  console.log("Sunday");
} else {
  console.log("Invalid");
}
```
