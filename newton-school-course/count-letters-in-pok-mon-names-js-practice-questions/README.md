## Problem Statement

In a Pok&eacute;mon registry, names are provided as a single string separated by commas. Write a function countLettersInPokemonNames that splits this string into an array of names, and returns an array with the count of letters in each name.

### Input
Input will be a single line of code, representing a string of comma-separated Pokémon names. It will always have at least one Pokémon name.

### Output
An array of integers where each integer is the count of letters in the corresponding Pokémon name.

### Example
Input:
pikachu, bulbasaur, charmander, squirtle

Output:
[7, 9, 10, 8]

## Solution

```js
function countLettersInPokemonNames(pokemonNamesStr) {
    return pokemonNamesStr.split(',').map(name => name.trim().length);
}
```
