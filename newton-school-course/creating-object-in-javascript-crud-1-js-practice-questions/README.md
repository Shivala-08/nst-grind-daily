## Problem Statement

You will receive id, name, age, passion, and gender as parameters in a function. Your task is to return an object from the function where these parameters are used as key-value pairs. Make sure that the returned contains only valid values(truthy-values).

### Input
The first line of input will contain space-separated string values in the following order. 

id, name, age, passion, gender

### Output
The output will be an object with the corresponding values assigned to the keys mentioned above.

### Example
Input
1997 shalu 27 travelling female

Output
{
 id: '1997',
 name: 'shalu',
 age: '27',
 passion: 'travelling',
 gender: 'female'
}

## Solution

```js
const createUserProfile = (id, name, age, passion, gender) => {
  const profile = {};

  if (id) profile.id = id;
  if (name) profile.name = name;
  if (age) profile.age = age;
  if (passion) profile.passion = passion;
  if (gender) profile.gender = gender;

  return profile;
};
```
