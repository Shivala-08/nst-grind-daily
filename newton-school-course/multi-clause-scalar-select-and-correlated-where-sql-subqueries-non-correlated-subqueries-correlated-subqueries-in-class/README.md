## Problem Statement

Scenario: The performance team wants a single report that shows only above-branch-average accounts, displays each account&#39;s branch average alongside its balance, calculates the difference, and flags whether the account is significantly or only moderately above average.

Table: accounts

+----------------+---------------+
| Column | Type |
+----------------+---------------+
| account_id | INT (PK) |
| account_holder | VARCHAR(50) |
| branch | VARCHAR(20) |
| account_type | VARCHAR(20) |
| account_status | VARCHAR(10) |
| balance | DECIMAL(12,2) |
| opened_date | DATE |
+----------------+---------------+

Table: transactions

+------------+----------------------+
| Column | Type |
+------------+----------------------+
| txn_id | INT (PK) |
| account_id | INT (FK &rarr; accounts) |
| txn_amount | DECIMAL(12,2) |
| txn_type | VARCHAR(10) |
| txn_date | DATE |
+------------+----------------------+

Tasks:

1. Filter to accounts whose balance exceeds their branch average using a correlated WHERE subquery.

2. Add a branch_avg column to the SELECT list using a correlated scalar subquery.

3. Add a balance_diff column computed as balance minus branch_avg.

4. Round balance, branch_avg, and balance_diff to 2 digits.

5. Add ORDER BY balance_diff DESC.

6. Add a CASE column labelled performance_label: &#39;Significantly Above&#39; if balance_diff &gt; 1,00,000, and &#39;Moderately Above&#39; otherwise.

### Output

----------------+-----------+-----------+------------+--------------+---------------------
 Ravi Kumar | Mumbai | 310000.00 | 150066.67 | 159933.33 | Significantly Above
 Priya Mehta | Bangalore | 128000.00 | 95000.00 | 33000.00 | Moderately Above
(2 rows)

## Solution

```js
SELECT 
    account_holder, 
    branch, 
    ROUND(balance, 2) AS balance,
    ROUND((SELECT AVG(balance) FROM accounts WHERE branch = a.branch), 2) AS branch_avg,
    ROUND(balance - (SELECT AVG(balance) FROM accounts WHERE branch = a.branch), 2) AS balance_diff,
    CASE 
        WHEN balance - (SELECT AVG(balance) FROM accounts WHERE branch = a.branch) > 100000 THEN 'Significantly Above'
        ELSE 'Moderately Above'
    END AS performance_label
FROM accounts a
WHERE balance > (
    SELECT AVG(balance)
    FROM accounts
    WHERE branch = a.branch
)
ORDER BY balance_diff DESC;
```
