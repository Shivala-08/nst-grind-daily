## Problem Statement

You are given a MongoDB collection named employees. Each document in the collection has the following structure:

{
 "name": String,
 "age": Number,
 "department": String,
 "salary": Number
}

Write a MongoDB query to find all employees who satisfy the following condition:

The employee is neither from the Sales department nor is their age greater than 25. Modify the query to return only name, age, and department fields (exclude _id).

## Solution

```js
db.employees.find(
  {
    $nor: [
      { department: "Sales" },
      { age: { $gt: 25 } }
    ]
  },
  {
    name: 1,
    age: 1,
    department: 1,
    _id: 0
  }
)
```
