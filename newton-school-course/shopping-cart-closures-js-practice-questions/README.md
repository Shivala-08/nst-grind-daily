## Problem Statement

An e-commerce website needs a shopping cart.

Create a function createCart() that returns an object containing three methods to manage a shopping cart:

 * Add items: addItem(itemName) &rarr; adds an item to the cart

 * Remove items: removeItem(itemName) &rarr; removes one occurrence of the item

 * Get total items: getTotalItems() &rarr; returns total number of items in the cart

Rules:

 * Cart data must be private is stored in an array. 

 * You must use closures

 * Do not use global variables

 

The output of your createCart function will be checked by executing it with the following example code:

const cart = createCart();
cart.addItem("apple");
cart.addItem("banana");
cart.removeItem("apple");
console.log(cart.getTotalItems()); // 1

 

### Input
First line: space-separated item names to add to the cart.
Second line: space-separated item names to remove from the cart.

### Output
Return an object containing three functions.

### Example
INPUT 1:
pineapple orange banana
orange banana

OUTPUT 1:
Total items in cart : 1

EXPLANATION:

## Solution

```js
function createCart() {
  // The cart array acts as private data, hidden from the global scope
  let cart = [];

  return {
    addItem: function(itemName) {
      cart.push(itemName);
    },
    removeItem: function(itemName) {
      // Find the first occurrence of the item
      const index = cart.indexOf(itemName);
      
      // If the item exists in the array, remove exactly one instance of it
      if (index !== -1) {
        cart.splice(index, 1);
      }
    },
    getTotalItems: function() {
      return cart.length;
    }
  };
}
```
