## Problem Statement

A collection named patients stores health records for a city hospital. Each patient document is structured as follows:

 

{

 _id: ObjectId,

 name: String,

 department: String,

 status: String,

 contact: {

 phone: String,

 email: String

 },

 admitted: Boolean

}

 

The hospital wants to update the phone number of a patient named "Sunil" who is in the "Cardiology" department. The new phone number is "9876543210". Only the first matching document should be updated.

Write the MongoDB query to perform this update. After updating the document, also query for that specific document in the mentioned collection.

## Solution

```js
db.patients.updateOne(
  { name: "Sunil", department: "Cardiology" },
  { $set: { "contact.phone": "9876543210" } }
);

db.patients.find({ name: "Sunil", department: "Cardiology" });
```
