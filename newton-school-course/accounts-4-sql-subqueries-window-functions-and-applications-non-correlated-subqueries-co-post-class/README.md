## Problem Statement

A bank maintains customer account information. The analytics team wants to use different types of subqueries in the WHERE clause to filter accounts based on balance and branch conditions.

ACCOUNTS

+------------+---------------+----------+---------+
| account_id | customer_name | branch | balance |
+------------+---------------+----------+---------+
| 101 | Aarav | Pune | 50000 |
| 102 | Diya | Pune | 80000 |
| 103 | Vivaan | Mumbai | 45000 |
| 104 | Ananya | Mumbai | 90000 |
| 105 | Ishaan | Delhi | 70000 |
| 106 | Meera | Chennai | 60000 |
+------------+---------------+----------+---------+

Write SQL queries for the following:

Display accounts that do not belong to branches having any account with a balance greater than 75,000.

 

### Output
 account_id | customer_name | branch | balance 
------------+---------------+---------+---------
 105 | Ishaan | Delhi | 70000
 106 | Meera | Chennai | 60000
(2 rows)

## Solution

```js
SELECT * 
FROM accounts 
WHERE branch NOT IN (
    SELECT branch 
    FROM accounts 
    WHERE balance > 75000
);
```
