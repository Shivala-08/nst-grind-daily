## Problem Statement

You are tasked to implement a function called myFind.

The myFind function should take two arguments:

 * An array of elements.

 * A callback function that is applied to each element in the array. This callback function takes two arguments. First is the current element, second is the current index.

The function should iterate over the array and return the first element for which the callback function returns true. If no element satisfies the condition, return undefined.

 

### Input
first line of input is an array
second line of input is the callback function in oneline

### Output
first element for which the callback function returns true.

### Example
Input
[1,2,3]
(item)=&gt; item%2===0

Output
2

Explanation

 * When each element of the array is passed into the callback function (item) =&gt; item % 2 === 0, the callback checks if the element is divisible by 2 (i.e., it is an even number).

 * The first element that satisfies this condition is 2, so 2 is returned as the output.

## Solution

```js
function myFind(arr, callback) {
  for (let i = 0; i < arr.length; i++) {
    // Pass the current element and its index to the callback function
    if (callback(arr[i], i)) {
      return arr[i]; // Return the first element that satisfies the condition
    }
  }
  return undefined; // Return undefined if no element satisfies the condition
}
```
