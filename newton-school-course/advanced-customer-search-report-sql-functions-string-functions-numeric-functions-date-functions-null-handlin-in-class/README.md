## Problem Statement

A customer success team needs a formatted, searchable customer profile export for a third-party CRM tool. The export has strict formatting requirements: names must be in uppercase, phone numbers must use dashes instead of spaces, registration dates must be human-readable, and a unique profile code must be generated.

Table schema:

CREATE TABLE customer_profiles (
 cust_id INT,
 first_name VARCHAR(50),
 last_name VARCHAR(50),
 phone VARCHAR(20), -- e.g. &#39;98765 43210&#39;
 reg_date DATE,
 tier VARCHAR(20) -- e.g. &#39;gold&#39;, &#39;silver&#39;
);

customer_profiles table:

| 104 | Sneha | Gupta | 95555 44444 | 2025-04-05 | bronze |
| 105 | Vikram | Singh | 90000 11111 | 2025-05-18 | silver |
+---------+------------+-----------+-------------+------------+--------+

Tasks:

1. Create a full_name column in the format &#39;SHARMA, RAHUL&#39; using UPPER() and CONCAT().

2. Create a formatted_phone column by replacing spaces in the phone number with dashes using REPLACE(). Example: &#39;98765 43210&#39; &rarr; &#39;98765-43210&#39;.

3. Format the reg_date as &#39;15 March 2024&#39; using TO_CHAR(). Label this column joined_on.

4. Build a profile_code column using the format &#39;GOLD-SHA-1042&#39; &mdash; combining the uppercase tier, the first 3 uppercase letters of the last name, and the customer ID. Use UPPER(), SUBSTRING(), and CONCAT().

5. Order by tier and then cust_id.

## Solution

```js
SELECT 
    CONCAT(UPPER(last_name), ', ', UPPER(first_name)) AS full_name,
    REPLACE(phone, ' ', '-') AS formatted_phone,
    TO_CHAR(reg_date, 'DD FMMonth YYYY') AS joined_on,
    CONCAT(UPPER(tier), '-', UPPER(SUBSTRING(last_name FROM 1 FOR 3)), '-', cust_id) AS profile_code
FROM 
    customer_profiles
ORDER BY 
    tier, 
    cust_id;
```
