## Problem Statement

You are given an array of integers named inputArr. Your task is to iterate through the array and determine if each integer is positive, negative, or zero. For each number, print the appropriate message:

 * Print "The number is positive." if the number is greater than zero.

 * Print "The number is negative." if the number is less than zero.

 * Print "The number is zero." if the number is equal to zero.

 * Print "The element is not an integer." if the element is not an integer.

### Input
A number of integers seperated by spaces which will be used as an array 

### Output
Corresponding message for each integer.

### Example
Input:
-2 0 1 2

Output:
The number is negative.
The number is zero.
The number is positive.
The number is positive.

Input:
-2 "0" 1 2

Output:
The number is negative.
The element is not an integer.
The number is positive.
The number is positive.

Input:
-2 [] 1 2

Output:
The number is negative.
The element is not an integer.
The number is positive.
The number is positive.

## Solution

```js
// Assuming inputArr is already provided by the environment
for (let i = 0; i < inputArr.length; i++) {
  let element = inputArr[i];
  
  // Check if the element is an integer
  if (!Number.isInteger(element)) {
    console.log("The element is not an integer.");
  } else if (element > 0) {
    console.log("The number is positive.");
  } else if (element < 0) {
    console.log("The number is negative.");
  } else {
    console.log("The number is zero.");
  }
}
```
