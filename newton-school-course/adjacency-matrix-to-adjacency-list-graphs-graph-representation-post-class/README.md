## Problem Statement

Given the adjacency matrix adjMat of an undirected graph, convert it into its corresponding adjacency list representation.

## Solution

```py
def convertToAdjList(n, adjMat):
    adj_list = []
    for i in range(n):
        neighbors = []
        for j in range(n):
            if adjMat[i][j] == 1:
                neighbors.append(j)
        adj_list.append(neighbors)
    return adj_list
```
