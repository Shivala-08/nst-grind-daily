## Problem Statement

Write a program that takes an integer n as input and prints a diamond pattern of 2n-1 height.

### Input
First line will contain an integer n representing the number of rows in the top half of the diamond.

### Output
Print the diamond pattern of 2n-1 height.

### Example
Input
5

Output

## Solution

```js
// Assuming `n` is provided by the environment
// Top half of the diamond (including the middle row)
for (let i = 1; i <= n; i++) {
  let spaces = " ".repeat(n - i);
  let stars = "*".repeat(2 * i - 1);
  console.log(spaces + stars);
}

// Bottom half of the diamond
for (let i = n - 1; i >= 1; i--) {
  let spaces = " ".repeat(n - i);
  let stars = "*".repeat(2 * i - 1);
  console.log(spaces + stars);
}
```
