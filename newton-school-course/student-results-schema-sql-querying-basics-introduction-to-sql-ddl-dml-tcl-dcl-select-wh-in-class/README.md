## Problem Statement

A school maintains a table named STUDENT_RESULTS to store student marks information.

The table contains the following columns:

STUDENT_RESULTS
+--------------+---------------+
| Column Name | Data Type |
+--------------+---------------+
| student_id | INT |
| student_name | VARCHAR(100) |
| subject | VARCHAR(50) |
| marks | INT |
+--------------+---------------+

Sample Data

+------------+--------------+-------------+-------+
| student_id | student_name | subject | marks |
+------------+--------------+-------------+-------+
| 101 | Aarav | Mathematics | 78 |
| 102 | Diya | Science | 92 |
| 103 | Rohan | English | 65 |
| 104 | Meera | History | 28 |
| 105 | Kabir | Computer | 33 |
+------------+--------------+-------------+-------+

Write the query for following tasks -

1. Update the marks of student_id 103 to 85.

2. Delete the records of students whose marks are less than 35.

3. Display all remaining records using a SELECT statement.

### Output
UPDATE 1
DELETE 2
 student_id | student_name | subject | marks 
------------+--------------+-------------+-------
 101 | Aarav | Mathematics | 78
 102 | Diya | Science | 92
 103 | Rohan | English | 85
(3 rows)

## Solution

```js
UPDATE STUDENTS_RESULTS SET marks = marks+85 WHERE student_id = 103;
DELETE FROM STUDENTS_RESULTS WHERE marks<35;
SELECT * FROM STUDENTS_RESULTS
```
