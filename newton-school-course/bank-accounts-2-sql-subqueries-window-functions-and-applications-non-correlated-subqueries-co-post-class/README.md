## Problem Statement

A bank wants to identify accounts that have performed at least one transaction.
The analytics team needs a report showing only those accounts for which a matching transaction record exists.

ACCOUNTS

+------------+---------------+---------+
| account_id | customer_name | balance |
+------------+---------------+---------+
| 101 | Aarav | 50000 |
| 102 | Diya | 80000 |
| 103 | Vivaan | 45000 |
| 104 | Ananya | 90000 |
+------------+---------------+---------+

TRANSACTIONS

+----------------+------------+--------+
| transaction_id | account_id | amount |
+----------------+------------+--------+
| 1 | 101 | 5000 |
| 2 | 101 | 2000 |
| 3 | 103 | 3000 |
| 4 | 104 | 7000 |
+----------------+------------+--------+

Write a SQL query to display:

 account_id

 customer_name

 balance

for accounts that have at least one transaction.

 

### Output
 account_id | customer_name | balance 
------------+---------------+---------
 101 | Aarav | 50000
 103 | Vivaan | 45000
 104 | Ananya | 90000
(3 rows)

## Solution

```js
SELECT 
    account_holder, 
    branch, 
    balance 
FROM accounts a 
WHERE balance > (
    SELECT AVG(balance) 
    FROM accounts 
    WHERE branch = a.branch
);
```
