(account_id INT PK, customer_id INT nullable FK, account_type VARCHAR(20), balance DECIMAL(12,2))

Tasks:

1. Write a LEFT JOIN from customers to accounts returning customer_name, account_id, and balance.

2. Filter the result to show only customers with no account by adding WHERE account_id IS NULL.

### Output
 customer_name | account_id | balance 
---------------+------------+---------
 Karan Patel | | 
(1 row)

## Solution

```js
SELECT 
    c.customer_name, 
    a.account_id, 
    a.balance
FROM 
    customers c
LEFT JOIN 
    accounts a ON c.customer_id = a.customer_id
WHERE 
    a.account_id IS NULL;
```
