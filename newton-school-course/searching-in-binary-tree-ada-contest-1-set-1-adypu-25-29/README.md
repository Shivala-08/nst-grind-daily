## Problem Statement

You are given the root of a binary tree where each node stores an integer value.

You are also given an integer key.

Your task is to determine whether any node in the binary tree has a value equal to key.

Return 1 if there exists at least one node whose value is equal to key; otherwise, return 0.

## Solution

```py
'''
class Node:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
'''

def search(root, key):
    # Base case: if the tree or subtree is empty, or we found the key
    if root is None:
        return 0
    
    if root.val == key:
        return 1
        
    # Recursively search in the left and right subtrees
    if search(root.left, key) == 1 or search(root.right, key) == 1:
        return 1
        
    return 0
```
