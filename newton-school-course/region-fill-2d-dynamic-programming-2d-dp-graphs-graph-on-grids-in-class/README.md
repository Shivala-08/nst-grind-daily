## Problem Statement

An image is represented by an $M \times N$ integer grid \texttt{image} where \texttt{image[i][j]} represents the pixel value (color) of the image at row $i$ and column $j$ ($0$-based indexing, $0 \le i &lt; M$ and $0 \le j &lt; N$).

You are also given three integers $sr$, $sc$, and \texttt{color}. You should perform a flood fill on the image starting from the pixel $(sr, sc)$.

To perform a flood fill:
\begin{enumerate}
 \item Consider the starting pixel $(sr, sc)$ and its original color $C = \texttt{image[sr][sc]}$.
 \item Change the color of the starting pixel to \texttt{color}.
 \item Also, change the color of any 4-directionally adjacent pixels (up, down, left, or right) that have the same original color $C$, recursively.
 \item Propagate this change outward until no more eligible adjacent pixels exist.
\end{enumerate}

Output the modified image after performing the flood fill.

### Input
The first line contains five space-separated integers: $M$, $N$, $sr$, $sc$, and \texttt{color} ($1 \le M, N \le 50$, $0 \le sr &lt; M$, $0 \le sc &lt; N$, $0 \le \texttt{color} &lt; 65536$).

Each of the next $M$ lines contains $N$ space-separated integers, representing the pixel values of the initial image. Each pixel value is in the range $[0, 65535]$.

### Output
Output the image configuration after performing the flood fill. The output must consist of $M$ lines, each containing $N$ space-separated integers.

### Example
Input:
3 3 1 1 2
1 1 1
1 1 0
1 0 1

Output:
2 2 2
2 2 0
2 0 1

Explanation:
In the first sample, the image is of size $3 \times 3$. The starting pixel is $(sr, sc) = (1, 1)$ which has an original color of $1$. The target color is $2$.
All pixels that are 4-directionally connected to $(1, 1)$ and have the original color $1$ are highlighted in the grid:
\begin{itemize}
 \item Pixel $(1, 1)$ is the starting point.
 \item Pixels $(0, 0)$, $(0, 1)$, $(0, 2)$, $(1, 0)$, and $(2, 0)$ are connected and share color $1$.
 \item The pixels at $(1, 2)$ and $(2, 2)$ have color $0$ and $1$, respectively, but $(2, 2)$ is not 4-directionally connected to any other pixel of color $1$ in the flood filled region (it is separated by $(2, 1)$ of color $0$).
\end{itemize}
Thus, only the connected component of color $1$ is changed to color $2$.

## Solution

```py
from collections import deque
import sys


def flood_fill(
    image: list[list[int]], sr: int, sc: int, color: int
) -> list[list[int]]:
  m, n = len(image), len(image[0])
  orig = image[sr][sc]
  if orig == color:
    return image

  queue = deque([(sr, sc)])
  image[sr][sc] = color
  directions = ((-1, 0), (1, 0), (0, -1), (0, 1))

  while queue:
    r, c = queue.popleft()
    for dr, dc in directions:
      nr, nc = r + dr, c + dc
      if 0 <= nr < m and 0 <= nc < n and image[nr][nc] == orig:
        image[nr][nc] = color
        queue.append((nr, nc))

  return image


def main() -> None:
  data = sys.stdin.read().strip().split()
  if not data:
    return

  m = int(data[0])
  n = int(data[1])
  sr = int(data[2])
  sc = int(data[3])
  color = int(data[4])

  idx = 5
  image = []
  for _ in range(m):
    row = [int(x) for x in data[idx : idx + n]]
    image.append(row)
    idx += n

  result = flood_fill(image, sr, sc, color)
  for row in result:
    print(" ".join(map(str, row)))


if __name__ == "__main__":
  main()
```
