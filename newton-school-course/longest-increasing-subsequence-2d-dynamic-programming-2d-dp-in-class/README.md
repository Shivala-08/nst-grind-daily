## Problem Statement

Given an integer array nums, return the length of the longest strictly increasing subsequence.

Note: Duplicate numbers are not counted as increasing subsequence.

### Input
User Task
Since this is a functional problem, you don't have to input anything. You just need to complete the lengthOfLIS() function that takes an integer array nums as the parameter and returns the length of the longest strictly increasing subsequence.

Custom Input
The first line of the input contains a single integer n, representing the size of the array nums.
The second line of the input contains n space separated integers representing elements of the array nums.

### Output
Return the length of the longest strictly increasing subsequence.

### Example
Sample Input
16
0 8 4 12 2 10 6 14 1 9 5 13 3 11 7 15
Output
6
Explanation
Longest increasing subsequence is of length 6. There are many subsequences of length 6, but listing one of them: 0 2 6 9 13 15.

## Solution

```py
def lengthOfLIS(nums):
    if not nums:
        return 0
    
    tails = []
    for num in nums:
        left, right = 0, len(tails) - 1
        idx = len(tails)
        
        while left <= right:
            mid = (left + right) // 2
            if tails[mid] >= num:
                idx = mid
                right = mid - 1
            else:
                left = mid + 1
                
        
        if idx == len(tails):
            tails.append(num)
        else:
            tails[idx] = num
            
    return len(tails)
```
