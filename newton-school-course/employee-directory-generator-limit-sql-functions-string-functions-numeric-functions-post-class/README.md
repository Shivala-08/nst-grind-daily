## Problem Statement

HR wants to generate a clean employee directory. Names may have inconsistent formatting and need standardised display names and short-form employee codes built from their data.

Table schema:

CREATE TABLE employees (
 emp_id INT,
 first_name VARCHAR(50),
 last_name VARCHAR(50),
 department VARCHAR(50)
);

Employees table:

+--------+------------+-----------+------------+
| emp_id | first_name | last_name | department |
+--------+------------+-----------+------------+
| 101 | John | Smith | Sales |
| 102 | Emma | Johnson | Marketing |
| 103 | Liam | Williams | IT |
| 104 | Olivia | Brown | Finance |
| 105 | Noah | Davis | HR |
| 106 | Sophia | Miller | Operations |
+--------+------------+-----------+------------+

Tasks:

1. Build a display_name column that formats names as "Lastname, Firstname" (e.g., &#39;Sharma, Rohit&#39;). Use CONCAT().

2. Show an emp_code column by combining the first 3 characters of the last name (uppercase) with the emp_id. Example: &#39;SHA101&#39;. Use SUBSTRING() and CONCAT().

3. Order by last name and display the corresponding department name.

### Output
 display_name | emp_code | department 
----------------+----------+------------
 Brown, Olivia | BRO104 | Finance
 Davis, Noah | DAV105 | HR
 Johnson, Emma | JOH102 | Marketing
 Miller, Sophia | MIL106 | Operations

(6 rows)

## Solution

SELECT 
    CONCAT(last_name,',',first_name),
