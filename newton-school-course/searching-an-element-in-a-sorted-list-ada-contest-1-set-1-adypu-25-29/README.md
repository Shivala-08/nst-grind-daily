## Problem Statement

Given a list arr of n integers, sorted in non decreasing order and a number x. Your task is to check if the element x is present in the list or not.

Note: Since the test cases are executed multiple times, using a linear search leads to a Time Limit Exceeded (TLE) error. Therefore, the problem must be solved using an O(log n) time complexity approach.

### Input
 User Task
Since this is a functional problem, you don't have to input anything. 
Your task is to complete the function isPresent(), 
which takes three parameters as input:

n — the size of the array, 
arr — the sorted input array, 
x — the target integer.

Custom Input:
The first line of input contains an integer T, the number of test cases.

For each test case:

* The next line contains two integers separated by a space — the number of array elements n and the value x to search for.

* The following line contains n space-separated integers representing the array elements.

### Output
If the element is present in the array return 1, else return -1.

### Example
Input
2
5 6
1 2 3 4 6
5 2
1 3 4 5 6

Output
1
-1

Explanation
Testcase 1:
n = 5, x = 6
Array: [1, 2, 3, 4, 6]
The value x = 6 is present in the array → return 1.

Testcase 2:
n = 5, x = 2
Array: [1, 3, 4, 5, 6]
The value x = 2 is not present in the array → return -1.

## Solution

```py
def isPresent(n, arr, x):
    low = 0
    high = n - 1
    
    while low <= high:
        mid = (low + high) // 2
        
        if arr[mid] == x:
            return 1
        elif arr[mid] < x:
            low = mid + 1
        else:
            high = mid - 1
            
    return -1
```
