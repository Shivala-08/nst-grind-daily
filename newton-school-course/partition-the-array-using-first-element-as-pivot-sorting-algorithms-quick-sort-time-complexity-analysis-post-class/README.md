## Problem Statement

You are given an array arr of n distinct integers. Your task is to perform a single partition step of the QuickSort algorithm using the first element of the array as the pivot.

After partitioning, rearrange the array such that:

 * All elements smaller than the pivot appear to its left.

 * All elements greater than the pivot appear to its right.

The relative order of elements greater than the pivot should remain unchanged, and the relative order of elements smaller than the pivot should remain unchanged (except as modified by the standard single-pass partition step).

User Task

Since this is a functional problem, you don&#39;t have to worry about handling standard input or printing the output. You just have to complete the function partition_array() which contains the following arguments:

 * arr: The input array.

 * lo: starting index of array

 * hi: ending index of array

Return Value: Modify the given array in-place by partitioning it around the pivot, and return the final 0-based index of the pivot element (pivot_index).

### Input
The first line contains an integer N denoting the size of the array.

The next line contains N distinct space-separated integers denoting the elements of the array.

### Output
Return the final 0-based index of the pivot element (pivot_index). The given array should be modified in-place.

Custom Output

The first line will print the partitioned array as N space-separated integers.

The second line will print a single integer denoting the final 0-based index of the pivot element.

### Example
Input
8
6 1 4 7 13 10 17 19
Output
4 1 6 7 13 10 17 19
2
Explanation: The pivot is the first element, 6. Scanning left to right from index 1: 1 is smaller than 6, so it's swapped into position right after the pivot region. 4 is smaller than 6, so it's swapped in next. 7, 13, 10, 17, 19 are all greater than 6, so they stay in place relative to each other. Finally, the pivot 6 is swapped into its correct position &mdash; index 2 &mdash; giving [4, 1, 6, 7, 13, 10, 17, 19].

## Solution

```py
def partition_array(arr, lo, hi):
    # The pivot is the first element
    pivot = arr[lo]
    
    # i will track the boundary of elements smaller than the pivot
    i = lo + 1
    
    # Scan the array from left to right
    for j in range(lo + 1, hi + 1):
        if arr[j] < pivot:
            # Swap current element with the element at the boundary
            arr[i], arr[j] = arr[j], arr[i]
            # Move the boundary forward
            i += 1
            
    # Finally, place the pivot in its correct position 
    # by swapping it with the last smaller element
    arr[lo], arr[i - 1] = arr[i - 1], arr[lo]
    
    pivot_index = i - 1
    
    # Return ONLY the pivot index as required
    return pivot_index
```
