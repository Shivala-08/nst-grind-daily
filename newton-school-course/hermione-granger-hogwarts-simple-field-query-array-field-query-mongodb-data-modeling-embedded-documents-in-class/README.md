## Problem Statement

You are maintaining a students collection for Hogwarts School of Witchcraft and Wizardry. Each student document contains an array of spells they have learned, with details about each spell. Example document:

 "name": "Hermione Granger",

 "house": "Gryffindor",

 "student_id": "S101",

 "spells": [

 { "spell_name": "Lumos", "level": 3 },

 { "spell_name": "Alohomora", "level": 2 }

 ]

Task:

 * Hermione has improved her skill in a specific spell.

 * Update the level of the spell "Alohomora" to 5.

 * Make sure only the relevant spell inside the embedded spells array is updated.

 

### Output
{
 "name": "Hermione Granger",
 "house": "Gryffindor",
 "student_id": "S101",
 "spells": [
 { "spell_name": "Lumos", "level": 3 },
 { "spell_name": "Alohomora", "level": 5 }
 ]
}

## Solution

```js
db.students.updateOne(
  {
    name: "Hermione Granger",
    "spells.spell_name": "Alohomora"
  },
  {
    $set: {
      "spells.$.level": 5
    }
  }
);
```
