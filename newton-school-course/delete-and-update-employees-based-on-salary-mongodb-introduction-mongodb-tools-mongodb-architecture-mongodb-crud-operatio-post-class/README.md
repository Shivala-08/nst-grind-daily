## Problem Statement

You are given a MongoDB collection named employees. Each document in the collection has the following structure:

{
 "_id": ObjectId,
 "name": String,
 "age": Number,
 "department": String,
 "salary": Number
}

Write two MongoDB queries:

 * Delete all employees whose salary is less than 40,000.

 * Update the salary of all remaining employees by increasing it by 5,000.

## Solution

```js
// 1. Delete all employees whose salary is less than 40,000
db.employees.deleteMany({ salary: { $lt: 40000 } });

// 2. Increase the salary of all remaining employees by 5,000
db.employees.updateMany({}, { $inc: { salary: 5000 } });
```
