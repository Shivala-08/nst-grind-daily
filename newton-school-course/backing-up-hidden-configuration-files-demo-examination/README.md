## Problem Statement

A web app keeps its secret settings in hidden files, whose names start with a dot. Before the app is updated, back up its secret settings, remove an old cache file, and tighten the permissions on the secrets.

Given Directory Structure

app/
├── .cache_tmp (hidden)
├── .env (hidden: the secret settings)
├── .settings (hidden)
├── main.py
└── README.txt

A plain listing of app shows only main.py and README.txt. Use the listing option that shows all files to check your work.

Tasks

 * Create a folder named backup in the current folder and copy app/.env into it with the name env_backup.txt.

 * Delete the hidden file app/.cache_tmp. Every other file in app must stay.

 * Rename the hidden file app/.settings to app/settings.txt, so that it is no longer hidden.

 * The secrets in app/.env must be private: only the owner can read and write the file, and the group and others have no access.

Expected Structure

app/
├── .env (owner read and write only)
├── main.py
├── README.txt
└── settings.txt
backup/
└── env_backup.txt

## Solution

```js
mkdir -p backup
cp app/.env backup/env_backup.txt
rm -f app/.cache_tmp
mv app/.settings app/settings.txt
chmod 600 app/.env
ls -la app backup
```
