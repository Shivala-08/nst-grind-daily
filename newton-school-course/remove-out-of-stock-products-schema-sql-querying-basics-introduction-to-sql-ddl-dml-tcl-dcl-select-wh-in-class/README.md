## Problem Statement

You are given a products table (product_id, product_name, stock). Delete every product whose stock is 0, then return the remaining products (product_id, product_name, stock) .

The products table initially contains:

+------------+--------------+-------+
| product_id | product_name | stock |
+------------+--------------+-------+
| 1 | Notebook | 12 |
| 2 | Pen | 0 |
| 3 | Marker | 5 |
| 4 | Eraser | 0 |
+------------+--------------+-------+

### Output
DELETE 2
 product_id | product_name | stock 
------------+--------------+-------
 1 | Notebook | 12
 3 | Marker | 5
(2 rows)

## Solution

```js
DELETE products WHERE stock = 0;
SELECT product_id,product_name,stock FROM products
```
