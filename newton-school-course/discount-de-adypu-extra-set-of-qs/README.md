## Problem Statement

Write an SQL query to assign a discount rate of 10%, 20%, and 30% based on the order_amount.

 * order_amount less than 100 - 10%

 * order_amount between 100 and 500 - 20%

 * order_amount greater than 500 - 30% name the column as discount_rate

Display all the columns.

## Solution

```js
SELECT 
    order_id, 
    customer_name, 
    order_amount, 
    CASE 
        WHEN order_amount < 100 THEN '10%'
        WHEN order_amount BETWEEN 100 AND 500 THEN '20%'
        ELSE '30%'
    END AS discount_rate
FROM orders;
```
