## Problem Statement

Given a board of size $M \times N$ containing letters \texttt{'X'} and \texttt{'O'}. Rows of the board are numbered by integers from $1$ to $M$ from top to bottom, and columns of the board are numbered by integers from $1$ to $N$ from left to right. The cell $(x, y)$ is the cell on the intersection of row $x$ and column $y$ for $1 \le x \le M$ and $1 \le y \le N$.

Your task is to capture all regions of \texttt{'O'} cells that are completely surrounded by \texttt{'X'} cells. 

A region of \texttt{'O'} cells is considered surrounded if there is no path of adjacent \texttt{'O'} cells (connected horizontally or vertically) that can reach any cell on the boundary of the board (i.e., the first row, the last row, the first column, or the last column).

To capture a surrounded region, you must replace all of its \texttt{'O'} cells with \texttt{'X'} cells. Any \texttt{'O'} region that is connected to the boundary must not be modified.

### Input
The first line contains two integers $M$ and $N$ ($1 \le M, N \le 200$)~--- the number of rows and columns of the board, respectively.

Each of the next $M$ lines contains a string of length $N$, consisting only of uppercase characters \texttt{'X'} and \texttt{'O'}.

### Output
Output the board configuration after capturing all surrounded regions. The output must consist of $M$ lines, each containing a string of length $N$.

### Example
Input:
4 4
XXXX
XOOX
XXOX
XOXX

Output:
XXXX
XXXX
XXXX
XOXX

Explanation:
In the first sample, the board is of size $4 \times 4$. The initial state is:
\begin{itemize}
 \item Row 1: \texttt{X X X X}
 \item Row 2: \texttt{X O O X}
 \item Row 3: \texttt{X X O X}
 \item Row 4: \texttt{X O X X}
\end{itemize}

- The \texttt{'O'} cell at $(4, 2)$ is on the bottom boundary, so it cannot be captured.
- The region of \texttt{'O'} cells at $(2, 2)$, $(2, 3)$, and $(3, 3)$ is completely surrounded by \texttt{'X'} cells and does not reach the boundary. Thus, it is captured and flipped to \texttt{'X'}.

The final state of the board is:
\begin{itemize}
 \item Row 1: \texttt{X X X X}
 \item Row 2: \texttt{X X X X}
 \item Row 3: \texttt{X X X X}
 \item Row 4: \texttt{X O X X}
\end{itemize}

from collections import deque
import sys


def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return

    m = int(data[0])
    n = int(data[1])
    grid = [list(data[2 + i]) for i in range(m)]

    queue: deque[tuple[int, int]] = deque()

    # Collect all boundary 'O' cells as starting points
    for r in range(m):
        for c in (0, n - 1):
            if 0 <= c < n and grid[r][c] == "O":
                grid[r][c] = "#"
                queue.append((r, c))

    for c in range(n):
        for r in (0, m - 1):
            if 0 <= r < m and grid[r][c] == "O":
                grid[r][c] = "#"
                queue.append((r, c))

    # BFS to mark all 'O' cells reachable from the boundary
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
    while queue:
        r, c = queue.popleft()
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == "O":
                grid[nr][nc] = "#"
                queue.append((nr, nc))

    # Flip surrounded 'O' -> 'X' and restore safe '#' -> 'O'
    for r in range(m):
        for c in range(n):
            if grid[r][c] == "O":
                grid[r][c] = "X"
            elif grid[r][c] == "#":
                grid[r][c] = "O"

    for row in grid:
        print("".join(row))


if __name__ == "__main__":
    solve()
