## Problem Statement

You are given a \`users\` table:

+---------+----------+------------------------+
| user_id | username | email |
+---------+----------+------------------------+
| 1 | alice | alice@gmail.com |
| 2 | bob | bob@yahoo.com |
| 3 | charlie | charlie@outlook.com |
+---------+----------+------------------------+

Return username and the registered domain as email_domain &mdash; the last two labels of the host (strip any subdomain: corp.yahoo.com &rarr; yahoo.com), lowercased. Order by user_id.

### Output
 username | email_domain 
----------+--------------
 alice | gmail.com
 bob | yahoo.com
 charlie | outlook.com
(3 rows)

## Solution

```js
SELECT 
    username, 
    LOWER(SPLIT_PART(email, '@', 2)) AS email_domain
FROM 
    users
ORDER BY 
    user_id;
```
