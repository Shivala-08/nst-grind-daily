## Problem Statement

Given an array arr[], find the first repeating element. The element should occur more than once and the index of its first occurrence should be the smallest.

Note:- The position you return should be according to 1-based indexing.

Note:- Return -1 if no such element exist.

### Input
User Task:
Since this will be a functional problem, you don't have to take input. You just have to complete the function first_repeated() that takes one parameter arr array .

Custom Input:
First line contains a single integer n- number of elements in the array.
Second line contains n integers of the array.

Constraints:
1 Input: 
7
1 5 3 4 3 5 6
Output: 
2
Explanation:
 5 appears twice and its first appearance is at index 2 which is less than 3 whose first the occurring index is 3.

Input: 
4
1 2 3 4
Output: 
-1
Explanation: 
All elements appear only once so answer is -1.

## Solution

```py
def first_repeated(arr):
    # Dictionary to store the frequency of each element
    freq = {}
    for num in arr:
        freq[num] = freq.get(num, 0) + 1
        
    # Find the first element with a frequency greater than 1
    for i in range(len(arr)):
        if freq[arr[i]] > 1:
            return i + 1  # 1-based indexing
            
    return -1
```
