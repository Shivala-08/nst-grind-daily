Function named calculateTotalCost that takes four numbers as parameters:

 
 basePrice

Using these parameters, perform the following calculations:

 * Total cost for 1 ticket(oneTicketCost) = basePrice + weekendSurcharge + imaxFee + bookingFee

 * Apply a 15% members discount(discount) on the total cost for 4 tickets. (Discount = 15% of total cost)

 * Final amount(finalAmount) after substracting discount from total cost

## Solution

```js
function calculateTotalCost(basePrice, weekendSurcharge, imaxFee, bookingFee) {
    let oneTicketCost = basePrice + weekendSurcharge + imaxFee + bookingFee;
    let totalCostForFour = oneTicketCost * 4;
    let discount = totalCostForFour * 0.15;
    let finalAmount = totalCostForFour - discount;
    
    console.log(`Total cost for 4 tickets: ₹${finalAmount}`);
}
```
