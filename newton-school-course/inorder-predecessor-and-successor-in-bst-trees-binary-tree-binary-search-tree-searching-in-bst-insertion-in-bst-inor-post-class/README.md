## Problem Statement

You are given the root of a binary search tree (BST) and an integer key. Your task is to find the inorder predecessor and inorder successor of the given key in the tree.

Note: 

 * The inorder predecessor is the node with the maximum value strictly smaller than the key.

 * The inorder successor is the node with the minimum value strictly greater than the key.

 * If the predecessor or successor does not exist, represent it as -1.

User Task

Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function find_pre_suc(), which takes the root node and the integer key as the input parameters.

### Input
The first line of input contains two space-separated integers, N and key, representing the number of nodes and the target value.
The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.

### Output
Return a list containing two integers representing the predecessor and successor respectively.

### Example
Input
7 65
50 30 70 20 40 60 80
Output
60 70
Explanation
The sorted values in the tree are [20, 30, 40, 50, 60, 70, 80]. For the key 65, the largest value strictly smaller than 65 is 60, and the smallest value strictly greater than 65 is 70.

class Node:

def find_pre_suc(root, key):
    pre = -1
    suc = -1
    
    curr = root
    while curr:
        if curr.val < key:
            pre = curr.val
            curr = curr.right
        else:
            curr = curr.left
            
    curr = root
    while curr:

            suc = curr.val
            curr = curr.left
        else:
            curr = curr.right
            
    return [pre, suc]
