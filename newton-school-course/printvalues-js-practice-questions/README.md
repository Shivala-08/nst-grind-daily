## Problem Statement

You are given an object with key-value pairs. Your task is to write a function called printValues that will:

 * Extract all the key values from the object.

 * Using the extracted keys, print each value strictly greater than 50 on a separate line.

### Input
For user-generated test cases:
1. The first line of input will contain the number of field the object should have, i.e. n.
2. Next n line contains : separated key-value pairs. Value should be a positive integer.

Note: You are not required to take any input. You will be given the object, you only have to print the values.

### Output
You must print all the values present in the object that are strictly greater than 50, one in each line.

### Example
Example 1:
Input:
3
Apple: 50
Banana: 60
Mango: 70

Output:
60
70

Example 2:
Input:
3
Developer: 55
Tester: 46
Designer: 73

Output:
55
73

## Solution

```js
function printValues(obj) {
  // Iterate through the object's values and print those greater than 50
  for (let key in obj) {
    if (obj[key] > 50) {
      console.log(obj[key]);
    }
  }
}
```
