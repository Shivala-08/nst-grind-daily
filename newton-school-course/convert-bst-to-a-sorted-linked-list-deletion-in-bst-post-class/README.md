## Problem Statement

You are given the root of a binary search tree (BST). Your task is to convert this tree into a sorted, single-linked list completely in-place using inorder traversal.

Note: 

 * You must reuse the existing tree nodes. The right pointer should point to the next node in the sorted sequence, and the left pointer should be set to null for all nodes.

 * The head of the linked list must point to the node with the smallest value in the BST.

User Task

Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function bst_to_sorted_list(), which takes the root node as the input parameter.

 

### Input
The first line of input contains an integer, N, representing the number of nodes in the tree.
The next line consists of space-separated integers denoting the level order traversal of the tree, where non-negative values represent node values, and -1 indicates a null node.

### Output
Return the head node of the newly created sorted singly linked list.

### Example
Input
3
4 2 5

Output
2 4 5

Explanation

The input represents the following Binary Search Tree (BST):

We perform an inorder traversal (Left → Root → Right), which always visits a BST's nodes in ascending sorted order:

 Visit 2 (left) → Visit 4 (root) → Visit 5 (right)

During traversal, we rewire the node pointers in-place:

Node 2 : left = null, right → Node 4
Node 4 : left = null, right → Node 5
Node 5 : left = null, right → null

The head of the linked list is the leftmost node (smallest value) = Node 2

Final linked list:

2 → 4 → 5 → null

Output prints the right-pointer chain from head to tail: 2 4 5

class Node:
    def __init__(self, val=0):

'''
import sys

sys.setrecursionlimit(200000)


def bst_to_sorted_list(root):
    dummy = Node(-1)
    prev = dummy

    def inorder(node):
        nonlocal prev
        if not node:
            return

        inorder(node.left)

        prev.right = node
        node.left = None
        prev = node

        inorder(node.right)

    inorder(root)
    return dummy.right
