Write the SQL query to display each patient&rsquo;s name from Pune, along with their total fees for each visit type (Checkup and Surgery), and the overall total fees, with the following requirements:

 * Include patients even if they have no appointments (treat fees as 0).

 * Include only patients whose overall total fees exceed 800.

## Solution

```js
SELECT 
    p.PatientName,
    COALESCE(SUM(CASE WHEN a.VisitType = 'Checkup' THEN a.Fees END), 0) AS Checkup,
    COALESCE(SUM(CASE WHEN a.VisitType = 'Surgery' THEN a.Fees END), 0) AS Surgery,
    COALESCE(SUM(a.Fees), 0) AS TotalFees
FROM 
    Patients p
LEFT JOIN 
    Appointments a ON p.PatientID = a.PatientID
WHERE 
    p.City = 'Pune'
GROUP BY 
    p.PatientID, p.PatientName
HAVING 
    TotalFees > 800
ORDER BY 
    TotalFees DESC, 
    p.PatientName ASC;
```
