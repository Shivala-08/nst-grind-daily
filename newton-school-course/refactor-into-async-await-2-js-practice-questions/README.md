## Problem Statement

You are given a JavaScript code snippet that uses .then or/and .catch to handle promises. You are tasked with refactoring the given code into handling the given function named asyncFunction with async and await.

### Input
Anything as a string will be settled(rejected) by asyncFunction

### Output
same as input

### Example

Explanation
3 was given as input and if the code is implemented correctly, the function asyncFunction will settle(reject) the promise with the data 3

## Solution

```js
async function handleAsync() {
  try {
    await asyncFunction();
  } catch (err) {
    console.log(err);
  }
}

handleAsync();
```
