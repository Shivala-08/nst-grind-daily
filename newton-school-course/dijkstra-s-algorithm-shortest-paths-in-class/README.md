## Problem Statement

Given an undirected, weighted graph and a source node. Your task is to compute the shortest path from the source node to all other nodes in the graph using Dijkstra&#39;s algorithm.

* n is the number of nodes in the graph (nodes are numbered from 0 to n-1),

* src is the source node from which shortest paths are to be calculated,

* edges is a 2D list of size m, where each element is a triplet [u, v, w] representing an undirected edge between node u and node v with weight w.

Custom Input

* The first line contains two integers n and m — the number of nodes and number of edges.

* The next m lines contain three integers u, v, and w — an undirected edge between node u and node v with weight w.

* The last line contains an integer src — the source node.

### Output
Return a list of integers where the i-th integer represents the shortest distance from the source node src to node i. If node i is unreachable from the source node src, return -1 for that node.

import heapq


def shortestPaths(n, src, edges):
  # Build undirected adjacency list: adj[u] = [(v, w), ...]
  adj = [[] for _ in range(n)]
  for u, v, w in edges:
    adj[u].append((v, w))
    adj[v].append((u, w))

  # Initialize distances with infinity
  inf = float('inf')
  dist = [inf] * n
  dist[src] = 0

  # Min-heap storing (current_distance, node)
  pq = [(0, src)]

  while pq:
    curr_dist, u = heapq.heappop(pq)

    # Skip stale entries if a shorter path to u was already found
    if curr_dist > dist[u]:
      continue

    for v, w in adj[u]:
      new_dist = curr_dist + w
      if new_dist < dist[v]:
        dist[v] = new_dist
        heapq.heappush(pq, (new_dist, v))

  # Replace unreachable (inf) nodes with -1
  return [-1 if d == inf else d for d in dist]
