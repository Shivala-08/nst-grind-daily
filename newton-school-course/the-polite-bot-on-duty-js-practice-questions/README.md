## Problem Statement

Aarav is building a smart service bot for his university&rsquo;s help desk.
This bot greets students politely when they log in. However, sometimes students forget to enter their names.
In such cases, the bot should automatically use &ldquo;Guest&rdquo; as the name.

Your task is to help Aarav write a function expression that behaves like this polite greeter.

Task

Write a JavaScript function expression assigned to a constant named greetUser.

The function should:

 
 Take one parameter, name.

 

 
 If no name is provided, the name should default to "Guest".

 

 
 Return a string in the format:

 "Welcome, &lt;name&gt;!" 

Input

The system will automatically call your function behind the scenes as:

If you don&rsquo;t provide any input, it will behave as if the function was called like:

Output

Print the greeting message returned by the function.

## Solution

const greetUser = function(name = "Guest") {
    return `Welcome, ${name}!`;
};
