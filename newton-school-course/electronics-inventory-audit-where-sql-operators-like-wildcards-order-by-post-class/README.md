## Problem Statement

An online marketplace stores product information in the products table.

A marketing analyst wants to retrieve only the products whose category is exactly &#39;Electronics&#39;.

Several categories in the database contain the word Electronics as part of a larger category name, such as Home Electronics and Electronics Accessories.

Write an SQL query to display the names of products that belong only to the category &#39;Electronics&#39;.
