## Problem Statement

You are provided with two integers, start and end. Write a JavaScript program to find the number of prime numbers in the range [start, end] (inclusive).

### Input
Inputs will always be positive integers represented by start and end.
10 20

### Output
4 (no of prime numbers in the given range inclusive).

### Example
Example 1:
start = 10;
end = 20;
Number of prime numbers between 10 and 20: 4 (11, 13, 17, 19)

Example 2:
start = 25;
end = 30;
Number of prime numbers between 25 and 30: 1

## Solution

```js
// start, end : variables are already defined, you have to directly use them

function countPrimes(start, end) {
  let count = 0;

  for (let num = start; num <= end; num++) {
    if (num <= 1) continue;
    let isPrime = true;
    
    for (let i = 2; i <= Math.sqrt(num); i++) {
      if (num % i === 0) {
        isPrime = false;
        break;
      }
    }
    
    if (isPrime) {
      count++;
    }
  }

  console.log(count);
}

countPrimes(start, end);
```
