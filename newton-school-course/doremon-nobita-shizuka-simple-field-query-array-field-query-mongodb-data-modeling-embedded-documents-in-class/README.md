You have a characters collection in the Doraemon universe. Each character has a name and a type (e.g., "Robot Cat", "Human").

Tasks:

"name": "Doraemon", "type": "Robot Cat" 

"name": "Nobita", "type": "Human"

3. Write a query to count how many Robot Cat characters exist.

## Solution

```js
db.characters.insertMany([
  { name: "Doraemon", type: "Robot Cat" },
  { name: "Nobita", type: "Human" },
  { name: "Shizuka", type: "Human" }
]);
db.characters.find({ type: "Human" });
db.characters.countDocuments({ type: "Robot Cat" });
```
