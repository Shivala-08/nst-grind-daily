## Problem Statement

Given a salary amount, calculate the tax based on the following slabs:

 * Salary up to 500,000: No tax (0%)

 * Salary more than 500,000 and up to 1,000,000: 10% tax

 * Salary more than 1,000,000 and up to 1,500,000: 20% tax

 * Salary more than 1,500,000: 30% tax

If the salary is less than or equal to zero, return a string "Salary not valid".

Implement the function findTax(salary) to return the calculated tax or the error message. Use JS Switch Case.

### Input
The findTax function would take salary as the only argument whose data type will be number

### Output
The findTax function returns the tax based on function calculation. 

### Example
Example 1:

Input: -100
Output: "Salary not valid"

## Solution

```js
function findTax(salary) {
  if (salary <= 0) {
    return "Salary not valid";
  }

  // Using switch(true) to evaluate range conditions
  switch (true) {
    case (salary <= 500000):
      return 0;
      
    case (salary > 500000 && salary <= 1000000):
      return salary * 0.10;
      
    case (salary > 1000000 && salary <= 1500000):
      return salary * 0.20;
      
    case (salary > 1500000):
      return salary * 0.30;
      
    default:
      return 0;
  }
}
```
