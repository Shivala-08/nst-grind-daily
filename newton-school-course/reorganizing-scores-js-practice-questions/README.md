## Problem Statement

You are tasked with writing a function named analyzeExamScores to analyze the performance of five students who participated in an exam that uses negative marking.

The Function must be doing following operations:

One of the students has received a negative score due to penalties, and we need to remove this student&#39;s score from the list.

After that, we will separate the remaining students into two groups:

 * Students with scores above 30.

 * Students with scores 30 or below.

Once the scores are separated, you need to return a single array that combines the pass scores first, followed by the fail scores.

 

### Input
scores: an input array containing the scores of 5 students in exam
negativeScoreIndex: an integer representing index of the negative number

### Output
A single array that first contains the passing scores, followed by the failing scores. without having negative numbers

### Example
Input: 
[25, 45, 18, -5, 38]
3

Output: 
[45, 38, 25, 18]

## Solution

```js
function analyzeExamScores(scores, negativeScoreIndex) {
    // 1. Remove the negative score using the provided index
    const validScores = scores.filter((_, index) => index !== negativeScoreIndex);

    // 2. Separate into pass (above 30) and fail (30 or below)
    const passScores = validScores.filter(score => score > 30);
    const failScores = validScores.filter(score => score <= 30);

    // 3. Return the combined array
    return [...passScores, ...failScores];
}
```
