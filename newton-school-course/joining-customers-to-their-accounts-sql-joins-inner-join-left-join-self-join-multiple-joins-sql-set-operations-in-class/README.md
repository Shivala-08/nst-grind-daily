## Problem Statement

Scenario: Newton Bank wants a single report that pairs each customer with their account details. Producing this with a separate subquery per customer is slow; a join does it in one pass.

Table: customers

+-------------+---------------+-------+-------------+
| customer_id | customer_name | city | referred_by |
+-------------+---------------+-------+-------------+
| 1 | Amit Sharma | Mumbai | NULL |

| 5 | Karan Patel | Bangalore | NULL |
+-------------+---------------+-------+-------------+
(customer_id INT PK, customer_name VARCHAR(50), city VARCHAR(30), referred_by INT nullable)

Table: accounts

+------------+-------------+--------------+---------+
| account_id | customer_id | account_type | balance |
+------------+-------------+--------------+---------+
| 101 | 1 | Savings | 45200 |
| 102 | 1 | Current | 95000 |
| 103 | 2 | Premium | 310000 |
| 104 | 3 | Savings | 62000 |
| 105 | 4 | Current | 8900 |
| 106 | NULL | Savings | 27000 |
+------------+-------------+--------------+---------+
(account_id INT PK, customer_id INT nullable FK, account_type VARCHAR(20), balance DECIMAL(12,2))

Tasks:

1. Write an INNER JOIN between customers and accounts on customer_id that returns customer_name, account_type, and balance.

2. Add ORDER BY balance DESC to the query.

### Output
 customer_name | account_type | balance 
---------------+--------------+-----------
 Priya Mehta | Premium | 310000.00
 Amit Sharma | Current | 95000.00
 Ravi Kumar | Savings | 62000.00
 Amit Sharma | Savings | 45200.00
 Sneha Iyer | Current | 8900.00
(5 rows)

## Solution

```js
SELECT 
    c.customer_name, 
    a.account_type, 
    a.balance
FROM 
    customers c
INNER JOIN 
    accounts a ON c.customer_id = a.customer_id
ORDER BY 
    a.balance DESC;
```
