## Problem Statement

You are given a list of N students, where each student has a name and marks. Your task is to sort the students using the QuickSort algorithm based on the following rules:
 

 * Sort students in increasing order of their marks.

 * If two students have identical marks, resolve the tie by sorting them in lexicographical (alphabetical) order of their names.

User Task

Complete the function sort_students(students), where students is a list of sublists formatted as [name, marks]. You do not need to handle input or output.

### Input
The first line contains an integer N denoting the number of students.

The next N lines each contain a string denoting the name and an integer denoting the marks of a student.

### Output
Return the fully sorted list of students following the sorting rules specified above as [name, marks].

Custom Output
The system will print N lines — each line containing the name and marks of a student in the final sorted order.

```py
def sort_students(students):
    # Base case: A list of zero or one elements is already sorted
    if len(students) <= 1:
        return students
    
    # Choose a pivot (we use the middle element here)
    pivot = students[len(students) // 2]
    pivot_name, pivot_marks = pivot[0], pivot[1]
    
    left = []
    middle = []
    right = []
    
    for student in students:
        name, marks = student[0], int(student[1])
        
        # Condition 1: marks are less than pivot marks
        # Condition 2: marks are equal, but name comes first alphabetically
        if marks < pivot_marks or (marks == pivot_marks and name < pivot_name):
            left.append(student)
            
        # Condition 1: marks are greater than pivot marks
        # Condition 2: marks are equal, but name comes later alphabetically
        elif marks > pivot_marks or (marks == pivot_marks and name > pivot_name):
            right.append(student)
            
        # Exactly equal to the pivot
        else:
            middle.append(student)
            
    # Recursively apply quicksort and combine
    return sort_students(left) + middle + sort_students(right)
```
