## Problem Statement

You are given an \`orders\` table:

+----------+---------------+------------+--------+
| order_id | customer_name | order_date | amount |
+----------+---------------+------------+--------+
| 1 | Aarav | 2025-07-05 | 1200 |
| 2 | Priya | 2025-06-28 | 850 |
| 3 | Rahul | 2025-07-18 | 2100 |
+----------+---------------+------------+--------+

Return the \`order_id\`, \`customer_name\`, and \`order_date\` of all orders placed in the **July 2025**.

Order the result by \`order_date\` in ascending order.

### Output
 order_id | customer_name | order_date 
----------+---------------+------------
 1 | Aarav | 2025-07-05
 3 | Rahul | 2025-07-18
(2 rows)

## Solution

```js
SELECT order_id, customer_name, order_date
FROM orders
WHERE order_date >= '2025-07-01' AND order_date <= '2025-07-31'
ORDER BY order_date ASC;
```
