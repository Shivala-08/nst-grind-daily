## Problem Statement

Given a grid of size $N \times M$. Rows of this grid are numbered by integers from $1$ to $N$ from top to bottom and columns of this grid are numbered by integers from $1$ to $M$ from left to right. The cell $(x, y)$ is the cell on the intersection of row $x$ and column $y$ for $1 \le x \le N$ and $1 \le y \le M$. Each cell $(x, y)$ has a non-negative traversal cost $A_{x, y}$. 

You start at the top-left cell $(1, 1)$ and want to reach the bottom-right cell $(N, M)$. In each step, you can move from your current cell to any of the $4$ adjacent cells (up, down, left, or right) that lie within the boundaries of the grid.

The cost of a path is defined as the sum of the traversal costs $A_{x, y}$ of all cells visited along the path, including both the starting cell $(1, 1)$ and the destination cell $(N, M)$.

It is guaranteed that the path from $(1, 1)$ to $(N, M)$ that minimizes the total cost is unique.

Output the number of cells in this path, followed by the $1$-based coordinates of each cell in order.

### Input
The first line contains two integers $N$ and $M$ ($1 \le N, M \le 1000$)~--- the number of rows and columns of the grid, respectively.

Each of the next $N$ lines contains $M$ space-separated integers, where the $j$-th integer on the $i$-th line represents the traversal cost $A_{i, j}$ ($0 \le A_{i, j} \le 10^9$) of the cell $(i, j)$.

### Output
On the first line, output a single integer $K$~--- the number of cells in the unique minimum cost path.

Each of the next $K$ lines should contain two space-separated integers $r_i$ and $c_i$~--- the $1$-based row and column coordinates of the $i$-th cell in the path. The first cell must be $(1, 1)$ and the last cell must be $(N, M)$.

### Example
Input:
3 3

\end{itemize}

The total minimum cost is $1 + 1 + 1 + 1 + 1 = 5$, and there are $5$ cells in this path. No other path from $(1, 1)$ to $(3, 3)$ has a smaller or equal cost.

    if u == target:

    c = u % m

      if nd < dist[v]:

    # Right
    if c + 1 < m:
      v = u + 1
