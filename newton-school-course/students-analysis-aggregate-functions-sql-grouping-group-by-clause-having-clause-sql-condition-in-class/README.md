## Problem Statement

A college maintains student records across multiple departments. The administration wants to know how many students belong to each department for resource planning and reporting.

STUDENTS TABLE

+------------+--------------+------------------+
| student_id | student_name | department |
+------------+--------------+------------------+
| 101 | Aarav | Computer Science |
| 102 | Diya | Information Tech |
| 103 | Vivaan | Computer Science |
| 104 | Ananya | Electronics |
| 105 | Ishaan | Information Tech |
| 106 | Rohan | Computer Science |
+------------+--------------+------------------+

Write SQL queries to:

 Display departments in alphabetical order along with their student count as student_count.

 Identify which department has the highest number of students.

### Output
 department | student_count 
------------------+---------------
 Computer Science | 3
 Electronics | 1
 Information Tech | 2
(3 rows)

 department | student_count 
------------------+---------------
 Computer Science | 3
(1 row)

## Solution

```js
SELECT department, COUNT(*) AS student_count
FROM students
GROUP BY department
ORDER BY department ASC;
SELECT department, COUNT(*) AS student_count
FROM students
GROUP BY department
ORDER BY student_count DESC
LIMIT 1;
```
