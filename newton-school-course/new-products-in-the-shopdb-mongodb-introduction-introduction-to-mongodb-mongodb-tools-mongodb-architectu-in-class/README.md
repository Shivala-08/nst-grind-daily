## Problem Statement

You&rsquo;re working with the database shopDB, which contains a collection named products.

Currently, each document in the products collection looks like this:

{

 "name": "String",

 "price": Number,

 "inStock": Boolean

}

Recently, the store decided to start tracking product categories and supplier names for some new items. These new fields haven&rsquo;t been part of the old schema yet.

Task: Insert the following two new product documents into the products collection using insertMany():

 Name: "Wireless Mouse", Price: 799, Category: "Electronics", Supplier: "GadgetMart"

 Name: "Cotton T-shirt", Price: 499, Category: "Apparel", Supplier: "FashionCo", inStock: true

Display all the inserted data and sort the output by name in Ascending Order.

## Solution

```js
use("shopDB");

db.products.insertMany([
  {
    name: "Wireless Mouse",
    price: 799,
    category: "Electronics",
    supplier: "GadgetMart"
  },
  {
    name: "Cotton T-shirt",
    price: 499,
    category: "Apparel",
    supplier: "FashionCo",
    inStock: true
  }
]);

db.products.find().sort({ name: 1 });
```
