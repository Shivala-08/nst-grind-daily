## Problem Statement

Find all valid combinations of k numbers that sum up to n such that the following conditions are true:

 1. Only numbers 1 through 9 are used.

 2. Each number is used at most once.

Return a list of all possible valid combinations. The list must not contain the same combination twice, and the combinations may be returned in any order.

### Input
User Task
Complete the function "CombinationSumThree()", that takes two integers k and n.

Custom Input
Input consists of two integers in the same line - k & n.

Constraints
1 Input
3 9

Output
1 2 6
1 3 5
2 3 4

Explanation
1 + 2 + 6 = 9
1 + 3 + 5 = 9
2 + 3 + 4 = 9
There are no other valid combinations.

## Solution

```py
def combinationSum3(k, n):
    res = []
    
    def backtrack(start, current_sum, comb):
        if len(comb) == k and current_sum == n:
            res.append(list(comb))
            return
        # Stop exploring if we exceed k numbers or the target sum n
        if len(comb) >= k or current_sum >= n:
            return
        
        for i in range(start, 10):
            comb.append(i)
            backtrack(i + 1, current_sum + i, comb)
            comb.pop()
            
    backtrack(1, 0, [])
    return res
```
