## Problem Statement

You are given a function customFilter which takes 3 arguments:

 * list - This is an array of objects. The object has key-value pairs. Eg: { date: 12, reading: 3, id: 20055 }. Note: This is just an example, the actual object in the list may contain more key-value pairs.

 * key and value.

 * You need to return an array from the function, which contains the id of all the objects having the given key: value pair.

Note:

 * Each object has the same number of keys and the same keys. Only the values differ per object

 * Each object in the array must have a key named id.

### Input
First Line is an integer N, that denotes the number of objects in the objects array list.
Then we have N lines. Each object of the array list is described in one line which has the key- value pairs for the object written as key1: value1, key2: value2,...and so on..
The last line has 2 space- separated values which denote the parameter key and value.

### Output
Return an array of ids from the objects which are filtered by the given key- value pair.

### Example
Sample Input:
2
date: 12, reading: 3, id: 20055
date: 12, reading: 3, id: 2055
reading 3
Sample Output:
20055
2055

Sample Input:
4
date: 11, reading: 3, id: 40055
date: 11, reading: 3, id: 4055
date: 13, reading: 4, id: 20055
date: 14, reading: 5, id: 2005
date 11
Sample Output:
40055
4055

## Solution

```js
function customFilter(list, key, value) {
  return list
    .filter(item => item[key] == value)
    .map(item => item.id);
}
```
