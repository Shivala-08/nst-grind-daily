## Problem Statement

Arav runs a social media platform where users earn badges based on how active they are.
Each user&rsquo;s activity is measured by how many posts they have made so far.

Your task is to help Arav assign the correct user tier based on their post count.

You need to write a function named getUserTier(postCount) that follows the logic below:

 
 If postCount &gt; 50, return "Gold User".

 

 
 If postCount is between 20 and 50 (inclusive), return "Silver User".

 

 
 If postCount &lt; 20, return "Bronze User".

 

### Input
25

### Output
Silver User

### Example

Output:
Silver User

Explanation:
Since 25 lies between 20 and 50 (inclusive), the condition
postCount &gt;= 20 && postCount &lt;= 50 becomes true.
Hence, the function returns "Silver User".

## Solution

```js
function getUserTier(postCount) {
    if (postCount > 50) {
        return "Gold User";
    } else if (postCount >= 20 && postCount <= 50) {
        return "Silver User";
    } else {
        return "Bronze User";
    }
}
```
