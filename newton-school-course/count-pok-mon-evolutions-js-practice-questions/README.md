## Problem Statement

For a Pok&eacute;mon database, each Pok&eacute;mon is represented as an object with a name and an evolutions property (an array of strings). Write a function countPokemonEvolutions that takes an array of such Pok&eacute;mon objects and returns an array of integers, where each integer is the count of evolutions for the corresponding Pok&eacute;mon.

### Input
Input will be a single line of code, representing an array of objects where each object has a name (string) and evolutions (array).

### Output
An array of integers where each integer is the count of evolutions for the corresponding Pokémon.

### Example
Input:
[ { "name": "Pikachu", "evolutions": ["Raichu"] }, { "name": "Bulbasaur", "evolutions": ["Ivysaur", "Venusaur"] } ]

Output:
[1, 2]

## Solution

```js
function countPokemonEvolutions(pokemonList) {
    return pokemonList.map(pokemon => pokemon.evolutions.length);
}
```
