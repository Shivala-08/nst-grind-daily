## Problem Statement

Given the adjacency list adjList of an undirected graph, convert it into its corresponding adjacency matrix representation.

Note: The value at the i-th row and j-th column of the adjacency matrix should be 1 if there is an edge between vertices i and j, and 0 if there is no such edge.

### Input
User Task
This is a function problem. You don’t have to take any input. You are required to complete the function convertToAdjMatrix that takes an integer n (number of vertices) and a 2D list adjList (the adjacency list of the graph) as parameters, and returns the adjacency matrix of the undirected graph.

Custom Input
The first line contains two integers, n and m, representing the number of vertices and the number of edges respectively.

The next m lines each contain two integers, representing an undirected edge between two vertices.

### Output

## Solution

```py
def convertToAdjMatrix(n, adjList):
    # Initialize an n x n matrix with zeros
    adjMatrix = [[0] * n for _ in range(n)]
    
    # Traverse each vertex and its neighbors in the adjacency list
    for i in range(n):
        for neighbor in adjList[i]:
            adjMatrix[i][neighbor] = 1
            
    return adjMatrix
```
