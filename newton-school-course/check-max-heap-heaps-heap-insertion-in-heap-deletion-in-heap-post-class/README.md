## Problem Statement

You are given an integer array arr of size n.

Assume this array represents a binary tree using 0-based indexing, where:

 
 The element at index 0 is the root.

 

 
 For any index i:

 
 
 The left child is at index 2 * i + 1

 

 
 The right child is at index 2 * i + 2

 

 
 

Your task is to check whether this array satisfies the Max-Heap property.

A valid Max-Heap satisfies the condition that every parent node is greater than or equal to its children (if they exist).

Return True if the array represents a valid Max-Heap, otherwise return False.

### Input
Your Task
Since this is a functional problem, you do not need to handle input or output. Your task is to complete the function is_max_heap(), which takes the arr as the input parameter.

Custom Input
First line contains an integer n - the size of array 
Next line contains n space separated integers denoting elements of array.

### Output
Return True if the array represents a max-heap otherwise return False

### Example
Input 1:

Output:
True

Explanation:

It is a max- heap as every node is greater than all of its descendants.
 
Input 2:

Output:

Explanation:

It is not a max- heap as 9 is less than its descendants (15, 10, 12, 11).

## Solution

```py
def is_max_heap(arr):
    n = len(arr)
    # We only need to check nodes that have at least one child.
    # In 0-indexed binary heaps, the internal nodes range from 0 to (n - 2) // 2.
    for i in range((n - 2) // 2 + 1):
        left = 2 * i + 1
        right = 2 * i + 2
        
        # Check if left child exists and is greater than the parent
        if left < n and arr[left] > arr[i]:
            return False
            
        # Check if right child exists and is greater than the parent
        if right < n and arr[right] > arr[i]:
            return False
            
    return True
```
