## Problem Statement

You are given an array arr of N integers. Your task is to perform a single partition step of the QuickSort algorithm using the last element of the array as the pivot.

Rearrange the array such that:

 * All elements less than or equal to the pivot appear to its left.

 * All elements greater than the pivot appear to its right.

 * The pivot is placed at its correct sorted position.

User Task

 * arr: The input array.

 * lo: starting index of array

 * hi: ending index of array

Return Value:

Your function must rearrange the given array in-place according to the partition process and return an integer representing the final 0-based index of the pivot element, i.e., pivot_index.

 

### Input
The first line contains an integer N denoting the size of the array.

The next line contains N space-separated integers denoting the elements of the array.

### Output

Custom Output

## Solution

```py
def partition_array(arr, lo, hi):
    # Choose the last element as the pivot
    pivot = arr[hi]
    
    # Index of the smaller element
    i = lo - 1
    
    # Traverse through all elements
    # compare them with the pivot
    for j in range(lo, hi):
        if arr[j] <= pivot:
            # If element smaller than or equal to pivot is found
            # swap it with the greater element pointed by i
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
            
    # Swap the pivot element with the greater element specified by i
    arr[i + 1], arr[hi] = arr[hi], arr[i + 1]
    
    # Return the position from where partition is done
    return i + 1
```
