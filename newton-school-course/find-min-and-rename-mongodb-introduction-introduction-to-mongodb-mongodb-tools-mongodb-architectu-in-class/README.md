## Problem Statement

You are given a MongoDB collection named employees. Each document has the following structure:

{
 "name": String,
 "age": Number,
 "dept": String, // Department name (note: the field is called "dept")
 "score": Number // Recent performance score
}

Write a MongoDB update query to do the following for all employees:

 * Ensure that no employee&#39;s score is above 60. If their current score is more than 60, update it to 60.

 * Rename the field dept to department across all documents.

After the update, fetch all employee records with only name, department, and score fields (hide _id).

## Solution

```js
db.employees.updateMany(
  {},
  [
    {
      $set: {
        score: { $min: ["$score", 60] },
        department: "$dept"
      }
    },
    {
      $unset: "dept"
    }
  ]
);
db.employees.find(
  {},
  {
    _id: 0,
    name: 1,
    department: 1,
    score: 1
  }
);
```
