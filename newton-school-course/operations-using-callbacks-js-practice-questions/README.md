## Problem Statement

The evaluate function:

 * It should check the value of the operation string.

 * If operation is "+", it should use the add function to return the sum of num1 and num2.

 * If operation is "-", it should use the sub function to return the difference of num1 and num2.

 * If operation is "*", it should use the mul function to return the product of num1 and num2.

 * If operation is "/", it should use the div function to return the quotient of num1 divided by num2.

Constraints:

 * You can assume that the input numbers are valid and that division by zero is not a concern for this implementation.

### Input
You will be given space-separated inputs, first and second will be numbers, third is going to be an operator.

### Output
The output should be the result of the arithmetic operation specified by the operation string, applied to num1 and num2.

### Example
Input
5 3 +

Output
8

Explanation
based on above inputs add function is called.

## Solution

```js
return function evaluate(num1, num2, operation, add, sub, mul, div) {
  switch (operation) {
    case "+":
      return add(num1, num2);
    case "-":
      return sub(num1, num2);
    case "*":
      return mul(num1, num2);
    case "/":
      return div(num1, num2);
    default:
      return null;
  }
};
```
