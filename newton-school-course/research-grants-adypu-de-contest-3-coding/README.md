## Problem Statement

A research institute awards grants to researchers for various projects. The institute wants to identify researchers whose grant amount is greater than the average grant amount awarded to other researchers in the same research department.

Write an SQL query to display the researcher ID, researcher name, department, and grant amount for every qualifying researcher.

A researcher must not be included in the department&#39;s average calculation when calculating their own comparison average. 

Display the results ordered by department alphabetically and grant amount in descending order.

## Solution

```js
SELECT
    researcher_id,
    researcher_name,
    department,
    grant_amount
FROM ResearchGrants rg
WHERE grant_amount > (
    SELECT AVG(grant_amount)
    FROM ResearchGrants
    WHERE department = rg.department
      AND researcher_id <> rg.researcher_id
)
ORDER BY
    department ASC,
    grant_amount DESC;
```
