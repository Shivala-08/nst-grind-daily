## Problem Statement

You are managing a MongoDB collection named students that stores information about university students. Each student document contains the following fields:

 * name (string)

 * age (number)

 * department (string)

Insert two new student documents into the students collection. 

{
 "name": "Alice",
 "age": 22,
 "department": "Computer Science"
}

{
 "name": "Bob",
 "age": 20,
 "department": "Mechanical Engineering"
}

 

Write a MongoDB query to retrieve all students whose age is greater than 21.
